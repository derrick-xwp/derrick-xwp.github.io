Cosmos 基本使用流程

源码：nvidia/cosmos · Cookbook：cookbooks/cosmos3/README.md

概述

Cosmos 开发遵循「环境准备 → 权重下载 → Cookbook/CLI 推理 →（可选）post-training → 部署」管线。

流程零：Cosmos 3 Cookbook（官方仓库结构）

已下载的 nvidia/cosmos 主仓库中，cookbooks/cosmos3/ 提供按后端划分的 notebook：

目录 后端 内容
cookbooks/cosmos3/reasoner/ vLLM · NIM · Cosmos Framework 视频 caption、grounding、物理推理
cookbooks/cosmos3/generator/audiovisual/ Diffusers · vLLM-Omni · Framework T2V/I2V、带音频生成
cookbooks/cosmos3/generator/action/ vLLM · Framework Forward dynamics、inverse dynamics、policy

环境前置（见 cookbooks/cosmos3/README.md）：

  • Linux + NVIDIA GPU（Ampere / Hopper / Blackwell）
  • uv · git · git-lfs
  • Hugging Face 登录：uvx hf@latest auth login（gated 模型需接受许可）
  • Framework 后端需额外 clone cosmos-framework 到 packages/cosmos3/：
git clone https://github.com/nvidia/cosmos.git
cd cosmos
mkdir -p packages
git clone https://github.com/NVIDIA/cosmos-framework.git packages/cosmos3
cd packages/cosmos3
export GIT_LFS_SKIP_SMUDGE=1
uv sync --all-extras --group=cu130-train   # CUDA 12.x 用 cu128-train

CUDA 驱动与 cu130 / cu128 对应关系见 Cookbook README；notebook 通过 COSMOS3_UV_GROUP 切换。

前置准备

硬件与软件

场景 最低建议
Cosmos 3 Nano 推理 NVIDIA RTX PRO 6000 或同等级 GPU；CUDA 12.x
Cosmos 3 Super Hopper / Blackwell（H100、B200 等）
Reason 2 边缘 Jetson Thor（见 Cookbook Jetson 配方）
Post-training 多 GPU 节点；Cosmos RL 支持分布式 rollout

克隆代码

git clone https://github.com/nvidia/cosmos.git
git clone https://github.com/NVIDIA/cosmos-framework.git

Hugging Face 认证

  1. 注册 Hugging Face 并接受对应模型许可（如 Cosmos3-Nano）。
  2. 创建 Access Token（Read）。
  3. 登录：
pip install huggingface_hub
huggingface-cli login
# 或 export HF_TOKEN=hf_...

权重示例：

  • nvidia/Cosmos3-Nano
  • nvidia/Cosmos3-Super
  • nvidia/Cosmos-Reason2-8B（遗留 Reason 2）

流程一：Cosmos 3 快速推理（cosmos-framework）

步骤 1：安装依赖

在 cosmos-framework 仓库根目录按 README / docs/inference.md 创建环境（通常为 Python 3.10+、PyTorch、CUDA 对齐版本）：

cd repos/cosmos-framework
# 具体命令以仓库 README 为准，常见模式：
pip install -e .

步骤 2：准备输入 JSON

框架使用 JSON 描述任务模式与媒体路径，示例位于 inputs/omni/（如 t2v.json 文本生视频）。

步骤 3：运行推理

python -m cosmos_framework.scripts.inference \
    --parallelism-preset=latency \
    -i "inputs/omni/t2v.json" \
    -o outputs/omni_nano \
    --checkpoint-path Cosmos3-Nano \
    --seed=0
参数 说明
--parallelism-preset latency（低延迟）/ 其他 preset 见 docs/inference.md
-i 输入配置 JSON
-o 输出目录
--checkpoint-path 本地或 HF 缓存中的 checkpoint 名/路径

步骤 4：检查结果

输出目录含生成视频 / 中间 tensor / 日志。失败时查 docs/inference.md 的 troubleshooting（CUDA、checkpoint 路径、并行度）。

流程二：Hugging Face Diffusers 快速体验

适合无需完整 framework 的 T2V / omni 管线验证：

# 以官方 HF 博客为准，模型发布后可用 Cosmos3OmniPipeline
from diffusers import Cosmos3OmniPipeline
import torch

pipe = Cosmos3OmniPipeline.from_pretrained(
    "nvidia/Cosmos3-Nano",
    torch_dtype=torch.bfloat16,
)
pipe.to("cuda")
# 按 pipeline API 传入 prompt / 条件帧

详见 HF Cosmos 3 博客。

流程三：Cosmos NIM 部署（生产推理）

Cosmos 3 Reasoner NIM 提供优化推理容器，适合 API 服务而非 post-training：

# 示例（端口与镜像 tag 以 NGC 文档为准）
docker run --gpus all -p 8000:8000 \
  nvcr.io/nim/nvidia/cosmos3-reasoner:latest
  • 推理 / API：优先 NIM
  • Post-training / 自定义数据：优先 cosmos-framework 源码

参考：Develop Physical AI with Cosmos 3

流程四：数据 Curation（Cosmos Curator）

Post-training 前常用 Curator 清洗视频：

  1. 按 Cookbook · Data Curation 安装 Ray + Curator 组件
  2. 流水线：切分 → caption → 过滤 → 去重 → 任务采样
  3. 输出供 Predict / Transfer / Reason 或 Cosmos 3 post-training 使用

典型分析：embedding 轨迹聚类、outlier 检测（见 Cookbook Cosmos Curator 章节）。

流程五：Post-training 领域适配

目标 方法 参考
机器人动作 / 轨迹 Action-conditioned fine-tune Cookbook · GR00T-Dreams、Cosmos Policy
Sim2Real 视频 Transfer depth/seg 控制 + LoRA Cookbook · CARLA Sim2Real
AV / 仓库 VQA Reason 2 SFT Cookbook · AV Video Caption VQA
大模型 RL Cosmos RL 分布式 rollout Cookbook · Model Post-Training

Cosmos 3 统一 post-training 脚本与 config 位于 cosmos-framework 与 nvidia/cosmos 文档。

流程六：与 Isaac Lab 组合（视觉增强）

  1. Isaac Lab 采集仿真 RGB（或 Replicator 输出）。
  2. Cosmos Transfer 2.5（或 Cosmos 3 等价模式）以 depth/seg 为 control，生成 photorealistic 帧。
  3. 将增强数据送回 Lab 感知训练或 offline IL。

Isaac 侧见 Lab 文档 augmented_imitation 与 Mimic 数据管线；Cosmos 侧见 Cookbook Sim2Real 类 recipe。

遗留工作流：Predict / Transfer / Reason 2.x

若项目仍绑定 2.x checkpoint，使用对应独立仓库：

# Predict 2.5 — 未来状态 / T2I / Video-to-World
cd repos/cosmos-predict2.5
# 按仓库 README 安装并运行 inference_*.py

# Transfer 2.5 — MultiControlNet Sim2Real
cd repos/cosmos-transfer2.5

# Reason 2 — VLM 推理（vLLM / 官方 sample）
cd repos/cosmos-reason2

各仓库 README 含 checkpoint 列表（general、robotics、multiview 等变体）。

常见问题

问题 处理
HF 403 / 未授权 在模型页接受许可；确认 huggingface-cli login
OOM 使用 Nano、降低分辨率、或 --parallelism-preset=latency
GitHub 克隆失败 配置代理或使用 fetch_repos.sh 中的镜像说明
旧教程指向 nvidia-cosmos/* 优先迁移至 github.com/nvidia/cosmos

更多配方与端到端案例见 在线资源与Cookbook.md。
