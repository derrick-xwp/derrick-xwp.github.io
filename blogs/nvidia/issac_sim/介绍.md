# Isaac Sim 技术介绍

> 官方仓库：[IsaacSim](https://github.com/isaac-sim/IsaacSim/blob/main)(https://github.com/isaac-sim/IsaacSim/blob/main/) · 版本见 [VERSION](https://github.com/isaac-sim/IsaacSim/blob/main/VERSION)  
> 资产与格式说明见 [不同格式3d文件的介绍.md](不同格式3d文件的介绍.md)；训练框架见 [../issac_lab/介绍.md](../issac_lab/介绍.md)。

## 1. 概述

NVIDIA Isaac Sim 是基于 **NVIDIA Omniverse** 与 **OpenUSD** 的机器人仿真平台，用于在虚拟环境中开发、测试和部署 AI 驱动的机器人系统（见 [README.md](https://github.com/isaac-sim/IsaacSim/blob/main/README.md)）。

- **高保真物理**：GPU 加速 PhysX 仿真  
- **多传感器**：RTX 相机、RTX LiDAR、物理传感器等  
- **数据与随机化**：Replicator 合成数据、域随机化  
- **生态集成**：ROS 2 桥接、Isaac Lab 强化/模仿学习  

Isaac Sim 提供**仿真后端**（场景、物理、渲染、传感器），**不**内置 RL/IL 训练循环；策略训练通常由上层 **[Isaac Lab](https://github.com/isaac-sim/IsaacLab)** 完成。

**资源**

- 在线文档：https://docs.isaacsim.omniverse.nvidia.com/latest/index.html  
- 产品页：https://developer.nvidia.com/isaac-sim

## 3. 主要功能

### 3.1 机器人建模与导入

README 明确支持的非 USD 导入类型：**URDF、MJCF、CAD**（[README.md L11](https://github.com/isaac-sim/IsaacSim/blob/main/README.md#L11)）。

| 格式 | 扩展 / 示例 | 说明 |
|------|-------------|------|
| **URDF** | [isaacsim.asset.importer.urdf](https://github.com/isaac-sim/IsaacSim/blob/main/source/extensions/isaacsim.asset.importer.urdf/) · [urdf_import.py](https://github.com/isaac-sim/IsaacSim/blob/main/source/standalone_examples/api/isaacsim.asset.importer.urdf/urdf_import.py) | 解析关节树，网格经 converter 进 USD |
| **MJCF** | [isaacsim.asset.importer.mjcf](https://github.com/isaac-sim/IsaacSim/blob/main/source/extensions/isaacsim.asset.importer.mjcf/) · [mjcf_import.py](https://github.com/isaac-sim/IsaacSim/blob/main/source/standalone_examples/api/isaacsim.asset.importer.mjcf/mjcf_import.py) | MuJoCo 模型 → USD |
| **CAD** | `omni.kit.converter.*` | 见 [isaacsim.exp.extscache.kit L353–361](https://github.com/isaac-sim/IsaacSim/blob/main/source/apps/isaacsim.exp.extscache.kit#L353-L361) |
| **OBJ / FBX / STL** | `omni.kit.asset_converter` | 见 [asset_usd_converter.py](https://github.com/isaac-sim/IsaacSim/blob/main/source/standalone_examples/api/omni.kit.asset_converter/asset_usd_converter.py) |

> **注意**：**Gazebo SDF** 机器人描述格式**不在**上述 README 与 importer 列表中。OpenUSD 依赖项中的 `sdf`（[repo.toml L287–291](https://github.com/isaac-sim/IsaacSim/blob/main/repo.toml#L287-L291)）指 **pxr.Sdf** 库，与 Gazebo 格式无关。

**内置机器人快捷菜单**（Create → Robots，完整资产见 Asset Browser）：

- Ant、Boston Dynamics Spot、Franka Panda、Humanoid、Nova Carter、Quadcopter  
- 源码：[create_menu.py L182–216](https://github.com/isaac-sim/IsaacSim/blob/main/source/extensions/isaacsim.gui.menu/isaacsim/gui/menu/create_menu.py#L182-L216)  

另有 UR10 等示例（[import_ur10.py](https://github.com/isaac-sim/IsaacSim/blob/main/source/extensions/isaacsim.asset.importer.urdf/python/impl/samples/import_ur10.py)、[ur_follow_target](https://github.com/isaac-sim/IsaacSim/blob/main/source/extensions/isaacsim.examples.interactive/isaacsim/examples/interactive/ur_follow_target/)），通过 URDF 或 `/Isaac/Robots/` 资产加载。

导入时通过 `import_config` 设置惯性等属性，碰撞等由 importer 写入 USD；导入后可在 Stage 上配置关节驱动等 PhysX 属性（[urdf_import.py L25–31、L66–81](https://github.com/isaac-sim/IsaacSim/blob/main/source/standalone_examples/api/isaacsim.asset.importer.urdf/urdf_import.py#L25-L31)；选项见 [api.rst](https://github.com/isaac-sim/IsaacSim/blob/main/source/extensions/isaacsim.asset.importer.urdf/docs/api.rst)）。

### 3.2 传感器模拟

Kit 基础应用加载的传感器扩展（[isaacsim.exp.base.kit L40–43](https://github.com/isaac-sim/IsaacSim/blob/main/source/apps/isaacsim.exp.base.kit#L40-L43)）：

| 类型 | 扩展 | 能力摘要 |
|------|------|----------|
| **相机（RGB / 深度等）** | `isaacsim.sensors.camera` | RGB、深度等图像输出；示例 [camera.py](https://github.com/isaac-sim/IsaacSim/blob/main/source/standalone_examples/api/isaacsim.sensors.camera/camera.py)（渲染经 Omniverse RTX 管线，见 [README Key Features](https://github.com/isaac-sim/IsaacSim/blob/main/README.md)） |
| **LiDAR / Radar** | `isaacsim.sensors.rtx` | RTX 激光雷达配置 · [extension.toml](https://github.com/isaac-sim/IsaacSim/blob/main/source/extensions/isaacsim.sensors.rtx/config/extension.toml) |
| **IMU / 接触 / 力矩** | `isaacsim.sensors.physics` | IMU：**线加速度、角速度、姿态**（无磁力计）· [OgnIsaacReadIMU.ogn](https://github.com/isaac-sim/IsaacSim/blob/main/source/extensions/isaacsim.sensors.physics/nodes/OgnIsaacReadIMU.ogn)；Contact / Effort · [extension.toml L5](https://github.com/isaac-sim/IsaacSim/blob/main/source/extensions/isaacsim.sensors.physics/config/extension.toml#L5) |
| **PhysX 射线等** | `isaacsim.sensors.physx` | 物理射线类传感器 |

语义分割、边界框等感知标注通常通过 **Replicator / SDG** 管线输出（见 §3.5）。

### 3.3 域随机化

- 扩展：`isaacsim.replicator.domain_randomization`（[isaacsim.exp.base.kit L31](https://github.com/isaac-sim/IsaacSim/blob/main/source/apps/isaacsim.exp.base.kit#L31)）  
- 可对光照、材质、物理参数、布局等做随机化，供 sim-to-real 与 SDG 使用。

### 3.4 遥操作与模仿学习数据

- **Isaac Sim** 提供仿真与 OpenXR 手部追踪等输入能力（[isaacsim.xr.openxr](https://github.com/isaac-sim/IsaacSim/blob/main/source/apps/isaacsim.exp.base.xr.openxr.kit)）。  
- **HDF5 演示录制、Robomimic、Isaac Lab Mimic** 属于 **Isaac Lab** 工具链，不在 IsaacSim-main 核心仓库中实现。  

### 3.5 合成数据生成（SDG）

- README 列为 Key Application：[Synthetic Data Generation](https://github.com/isaac-sim/IsaacSim/blob/main/README.md)  
- 基于 **Omniverse Replicator**（`isaacsim.replicator.*`），可批量输出 RGB、深度、分割、法线等模态及元数据。

### 3.6 GPU 加速与并行

- 物理与 RTX 渲染可在 GPU 上运行（README Key Features）。  
- Isaac Sim 提供 **GridCloner** 等克隆 API（[benchmark_core_world.py](https://github.com/isaac-sim/IsaacSim/blob/main/source/standalone_examples/benchmarks/benchmark_core_world.py)）。  
- **大规模并行 RL**（如数千 `num_envs`、PyTorch 张量接口）由 **Isaac Lab** 在 Isaac Sim 之上封装。

### 3.7 可变形体

- 支持 deformable / 软体相关 API 与测试（如 [test_deformable_prim_view.py](https://github.com/isaac-sim/IsaacSim/blob/main/source/extensions/isaacsim.core.api/python/tests/test_deformable_prim_view.py)）。

## 4. 使用方式与接口

### 4.1 图形界面

基于 Omniverse Kit：拖拽 USD 资产、调节仿真、使用 Replicator / 域随机化工具、Asset Browser 浏览 `/Isaac/Robots/` 等 Nucleus 资产。

### 4.2 Python API（当前推荐写法）

Standalone 示例统一使用 `isaacsim` 包（**非**已弃用的 `omni.isaac.kit` / `omni.isaac.core`）：

```python
from isaacsim import SimulationApp

simulation_app = SimulationApp({"headless": False})

from isaacsim.core.api import World
from isaacsim.core.api.objects import DynamicCuboid

world = World()
# ... 加载资产、步进仿真 ...
simulation_app.close()
```

完整入门：[standalone_examples/tutorials/getting_started.py](https://github.com/isaac-sim/IsaacSim/blob/main/source/standalone_examples/tutorials/getting_started.py)

### 4.3 ROS 2 桥接

- 扩展：**`isaacsim.ros2.bridge`**（[app selector 配置](https://github.com/isaac-sim/IsaacSim/blob/main/source/extensions/isaacsim.app.selector/isaacsim/app/selector/settings.py)）  
- 示例：[standalone_examples/api/isaacsim.ros2.bridge/](https://github.com/isaac-sim/IsaacSim/blob/main/source/standalone_examples/api/isaacsim.ros2.bridge/)  
- 支持 Humble / Jazzy 等；**ROS 1 桥接已标记 deprecated**（[selector CHANGELOG](https://github.com/isaac-sim/IsaacSim/blob/main/source/extensions/isaacsim.app.selector/docs/CHANGELOG.md)）。

## 5. 与 Isaac Lab 的分工

| | Isaac Sim | Isaac Lab |
|--|-----------|-----------|
| **职责** | 物理、渲染、传感器、USD 场景 | RL / IL 训练、任务库、并行 env、策略评估 |
| **调研文档** | 本文 | [../issac_lab/介绍.md](../issac_lab/介绍.md) |

典型链路：在 Isaac Sim 中准备 USD 场景与机器人 → Isaac Lab 加载为并行环境 → 定义 MDP / 奖励并训练 → 回到 Isaac Sim 或真机验证。
