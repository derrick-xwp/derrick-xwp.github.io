NVIDIA 具身平台调研 / Isaac Sim / 基本使用流程

你的理解基本正确，Isaac Sim 的典型工作流确实围绕 “资产导入 → 场景组装 → 仿真与数据采集” 展开。我来详细梳理一下标准步骤，并澄清你说的“读取数据的纹理”具体指什么。

Isaac Sim 基本工作流

第一步：准备 3D 资产（场景、物体、机器人）

你可以用任何 3D 建模工具（Blender、Maya、3ds Max、SolidWorks 等）制作：

  • 环境场景（地面、墙壁、桌面、货架）
  • 操作对象（箱子、工具、零件）
  • 自定义机器人（如果不用现成模型）

导出时，可以直接导出为 USD 或 USD 兼容格式（如 .usda, .usdc, .usdz），也可以先导出通用格式（.obj, .fbx, .gltf, .stl），后续由 Isaac Sim 自动转换。

第二步：导入 Isaac Sim 并转换为 USD

在 Isaac Sim 中：

  • 直接拖入任何支持格式的 3D 文件，引擎会自动调用内置转换器生成 USD 资产并缓存到本地。
  • 也可以使用 Python API 调用 omni.kit.asset_converter 进行批量转换。
  • 转换后的 USD 会保留网格、材质（基本PBR属性）、纹理路径等信息，但高级材质（如复杂的着色网络）可能需要重新在 Isaac Sim 中调整。

注意：你提到的“读取数据的纹理”——在这个阶段，纹理是作为资产的一部分存储在 USD 中的。Isaac Sim 使用 MDL（Material Definition Language） 或 OmniPBR 材质系统，导入的纹理（漫反射、法线、粗糙度贴图等）会被自动关联到对应材质通道。

第三步：组装场景并添加机器人

  • 从 Isaac Sim 自带的机器人库直接拖入 Franka、UR5、人形机器人等，或导入你自己转换的机器人 USD。
  • 给机器人添加物理属性：在 USD 中标记碰撞网格（collision purpose），设置质量、惯性、关节限位、驱动器参数等。
  • 摆放物体、设置障碍，利用 Isaac Sim 的PhysX 5 引擎确保物理交互真实。

第四步：配置传感器与域随机化

  • 添加相机、深度传感器、LiDAR、IMU、力传感器等。
  • 设置传感器参数（分辨率、FOV、噪声模型）。
  • （可选）设置域随机化：在 Isaac Sim 的 Domain Randomization 编辑器中，可以随机化纹理、颜色、光照、物体位置、物理属性等，让后续训练更鲁棒。

第五步：运行仿真并“读取数据”

这就是你所说的 “读取数据的纹理” 环节。仿真运行时，Isaac Sim 会实时计算物理并渲染传感器画面。你通过 Python 脚本可以获取：

# 获取当前相机图像（RGB 纹理）
import omni.replicator.core as rep
rgb = rep.get_rgb(camera)

# 获取深度图、分割标注等
depth = rep.get_depth(camera)
seg   = rep.get_semantic_segmentation(camera)

这些“纹理”本质上是 GPU 渲染出的图像数据，你可以直接保存为文件、录制成视频，或通过共享内存传给 PyTorch 做训练。

第六步：策略训练或数据录制

  • 如果你在用 Isaac Lab 进行强化学习或模仿学习，Isaac Sim 会作为后台运行，Isaac Lab 封装好环境并输出张量，直接给网络训练。
  • 如果你只做数据采集（合成数据生成），可以用 Omniverse Replicator 编写脚本，自动抓取各种随机化后的图像，输出带标注的数据集（COCO、YOLO 格式等）。

你提到的“读取数据纹理”补充说明

在仿真中，“纹理”通常指两种：

  1. 物体表面的纹理贴图（漫反射、法线等），已在导入时随材质加载，影响渲染外观。
  2. 传感器输出“图像”，也就是你运行仿真时从虚拟相机“看到”的画面，这才是你最终要采集的训练数据。

所以 Isaac Sim 的“读取纹理”更多是指实时获取相机渲染纹理，而不是单纯读取贴图文件。

总结流程图

建模/下载资产 (CAD, Blender, URDF等)
        ↓
导入 Isaac Sim → 自动转为 USD
        ↓
在 USD 场景中组装机器人、物体、传感器
        ↓
设置物理、材质、域随机化
        ↓
编写 Python 脚本控制仿真循环
        ↓
获取传感器纹理/数据（RGB、深度等）→ 用于训练或记录

按照这个流程，你就可以从零搭建一个物理精确的机器人仿真环境，并源源不断产生训练数据。如果还有哪个环节想深入了解（比如如何用 Python 批量导入并随机化场景），可以随时提问。
