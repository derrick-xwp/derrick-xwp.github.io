# Isaac Lab 使用流程（2.3.2）

> 源码根目录：[Isaac Lab 官方仓库](https://github.com/isaac-sim/IsaacLab/blob/main/) ·   
> 环境 MDP 配置在 `*_env_cfg.py`；RL 算法超参在 `config/<robot>/agents/rsl_rl_ppo_cfg.py` 或 `agents/*.yaml`。

## 概述

Isaac Lab 的使用遵循「场景定义 → 环境封装 → 训练 / 数据采集 → 评估与部署」管线。可直接使用 **Isaac Lab Tasks** 预置任务，或扩展框架自定义机器人与任务。

**启动脚本**：Linux / macOS 用 [isaaclab.sh](https://github.com/isaac-sim/IsaacLab/blob/main/isaaclab.sh)；Windows 用同目录下的 [isaaclab.bat](https://github.com/isaac-sim/IsaacLab/blob/main/isaaclab.bat)。下文命令以 `./isaaclab.sh` 为例，Windows 请将前缀替换为 `isaaclab.bat`。

---

## 前置准备：安装 Isaac Lab

1. **安装 Isaac Sim**（版本需与 Isaac Lab 兼容，见 [README.md](https://github.com/isaac-sim/IsaacLab/blob/main/README.md)）。
2. **官方仓库**：clone https://github.com/isaac-sim/IsaacLab。
3. **安装依赖**：
   ```bash
   cd IsaacLab
   ./isaaclab.sh --install
   ```
4. **验证安装**：
   ```bash
   ./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/train.py \
     --task Isaac-Cartpole-v0 --num_envs 4096 --headless
   ```

## 流程一：使用内置任务快速训练（强化学习）

### 步骤 1：选择预置任务

```bash
./isaaclab.sh -p scripts/environments/list_envs.py
```

脚本：[scripts/environments/list_envs.py](https://github.com/isaac-sim/IsaacLab/blob/main/scripts/environments/list_envs.py)

### 步骤 2：配置训练参数

- **环境 MDP**（观测 / 动作 / 奖励 / 终止）：编辑 `*_env_cfg.py`，例如四足基类 [velocity_env_cfg.py](https://github.com/isaac-sim/IsaacLab/blob/main/source/isaaclab_tasks/isaaclab_tasks/manager_based/locomotion/velocity/velocity_env_cfg.py)。
- **PPO 超参**：编辑 `agents/rsl_rl_ppo_cfg.py`，例如 [anymal_d/agents/rsl_rl_ppo_cfg.py](https://github.com/isaac-sim/IsaacLab/blob/main/source/isaaclab_tasks/isaaclab_tasks/manager_based/locomotion/velocity/config/anymal_d/agents/rsl_rl_ppo_cfg.py)。

```bash
./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/train.py \
  --task Isaac-Velocity-Rough-Anymal-D-v0 \
  --num_envs 4096 \
  --headless \
  --max_iterations 5000
```

### 步骤 3：训练与 Checkpoint

训练脚本：[scripts/reinforcement_learning/rsl_rl/train.py](https://github.com/isaac-sim/IsaacLab/blob/main/scripts/reinforcement_learning/rsl_rl/train.py)

Checkpoint 默认保存在：

```
logs/rsl_rl/<experiment_name>/<timestamp>/model_<iteration>.pt
```

其中 `<experiment_name>` 来自 agent 配置（如 Anymal D 为 `anymal_d_rough`），见对应 `rsl_rl_ppo_cfg.py` 中的 `experiment_name` 字段。

### 步骤 4：监控

```bash
tensorboard --logdir logs/rsl_rl
```

调试时可去掉 `--headless` 以打开 Isaac Sim 窗口。

### 步骤 5：加载模型并测试

```bash
./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/play.py \
  --task Isaac-Velocity-Rough-Anymal-D-v0 \
  --num_envs 64 \
  --checkpoint logs/rsl_rl/anymal_d_rough/<run_dir>/model_5000.pt
```

脚本：[scripts/reinforcement_learning/rsl_rl/play.py](https://github.com/isaac-sim/IsaacLab/blob/main/scripts/reinforcement_learning/rsl_rl/play.py)。也可省略 `--checkpoint`，由 agent 配置中的 `load_run` / `load_checkpoint` 自动解析。

## 流程二：模仿学习（以 Stack 为例）

以下以 Franka 堆叠任务为例，完整流程见官方文档 [teleop_imitation.rst](https://github.com/isaac-sim/IsaacLab/blob/main/docs/source/overview/imitation-learning/teleop_imitation.rst)。

**依赖**：Robomimic 需额外安装：

```bash
./isaaclab.sh -i robomimic
```

### 步骤 1：遥操作录制演示

```bash
./isaaclab.sh -p scripts/tools/record_demos.py \
  --device cpu \
  --task Isaac-Stack-Cube-Franka-IK-Rel-v0 \
  --teleop_device keyboard \
  --dataset_file ./datasets/dataset.hdf5 \
  --num_demos 10
```

脚本：[scripts/tools/record_demos.py](https://github.com/isaac-sim/IsaacLab/blob/main/scripts/tools/record_demos.py)。`--teleop_device` 还可选 `spacemouse`、`gamepad` 等。

### 步骤 2：标注子任务（Mimic 必需）

使用 **Mimic 环境**（带 `-Mimic` 后缀）对 HDF5 做子任务标注：

```bash
./isaaclab.sh -p scripts/imitation_learning/isaaclab_mimic/annotate_demos.py \
  --device cpu \
  --task Isaac-Stack-Cube-Franka-IK-Rel-Mimic-v0 \
  --auto \
  --input_file ./datasets/dataset.hdf5 \
  --output_file ./datasets/annotated_dataset.hdf5
```

脚本：[scripts/imitation_learning/isaaclab_mimic/annotate_demos.py](https://github.com/isaac-sim/IsaacLab/blob/main/scripts/imitation_learning/isaaclab_mimic/annotate_demos.py)

### 步骤 3：Mimic 扩增数据集

```bash
./isaaclab.sh -p scripts/imitation_learning/isaaclab_mimic/generate_dataset.py \
  --device cpu \
  --headless \
  --num_envs 10 \
  --generation_num_trials 1000 \
  --task Isaac-Stack-Cube-Franka-IK-Rel-Mimic-v0 \
  --input_file ./datasets/annotated_dataset.hdf5 \
  --output_file ./datasets/generated_dataset.hdf5
```

脚本：[scripts/imitation_learning/isaaclab_mimic/generate_dataset.py](https://github.com/isaac-sim/IsaacLab/blob/main/scripts/imitation_learning/isaaclab_mimic/generate_dataset.py)

`--task` 可省略：脚本会从 HDF5 元数据中推断环境名；显式指定 Mimic 环境更稳妥。

### 步骤 4：Robomimic 训练 BC 策略

训练时使用**原始遥操作环境 ID**（无 `-Mimic` 后缀），并指定算法 `--algo bc`：

```bash
./isaaclab.sh -p scripts/imitation_learning/robomimic/train.py \
  --task Isaac-Stack-Cube-Franka-IK-Rel-v0 \
  --algo bc \
  --dataset ./datasets/generated_dataset.hdf5
```

脚本：[scripts/imitation_learning/robomimic/train.py](https://github.com/isaac-sim/IsaacLab/blob/main/scripts/imitation_learning/robomimic/train.py)。模型与日志默认在 `logs/robomimic/` 下。

### 可选分支：SkillGen（CuRobo 运动规划扩增）

SkillGen 在 Mimic 基础上用 cuRobo 规划段间轨迹，需单独安装 cuRobo，流程见 [skillgen.rst](https://github.com/isaac-sim/IsaacLab/blob/main/docs/source/overview/imitation-learning/skillgen.rst)。与标准 Mimic 的区别：

| 项目 | 标准 Mimic | SkillGen |
|------|------------|----------|
| 标注 / 生成任务 ID | `Isaac-Stack-Cube-Franka-IK-Rel-Mimic-v0` | `Isaac-Stack-Cube-Franka-IK-Rel-Skillgen-v0` |
| `generate_dataset.py` | 不加 `--use_skillgen` | 加 **`--use_skillgen`** |
| 输入文件 | `annotated_dataset.hdf5` | 经 SkillGen 流程标注后的 HDF5 |

二者不要混用同一套参数。

## 流程三：自定义环境开发

### 步骤 1：在 Isaac Sim 中搭建场景（可选）

导入机器人 USD、物体、传感器，保存场景。

### 步骤 2：编写环境配置类

继承 `ManagerBasedRLEnvCfg`，定义：

- **`InteractiveSceneCfg` 子类**（如 `CartpoleSceneCfg`）：机器人与场景资产
- **`ObservationsCfg` / `ActionsCfg` / `RewardsCfg` / `TerminationsCfg`**
- 奖励实现写在 `mdp/rewards.py`，配置中通过 `RewTerm(func=mdp.xxx, weight=...)` 引用

**推荐模板**：[cartpole_env_cfg.py](https://github.com/isaac-sim/IsaacLab/blob/main/source/isaaclab_tasks/isaaclab_tasks/manager_based/classic/cartpole/cartpole_env_cfg.py)

Manager-Based 环境**不**在 env 类里手写 `_get_rewards()`；由 [`RewardManager`](https://github.com/isaac-sim/IsaacLab/blob/main/source/isaaclab/isaaclab/managers/reward_manager.py) 根据 `RewardsCfg` 自动加权求和（Direct 工作流除外，见 [任务基本介绍.md](任务基本介绍.md)）。

### 步骤 3：注册任务

在 `config/<robot>/__init__.py` 中 `gym.register(..., kwargs={"env_cfg_entry_point": ..., "rsl_rl_cfg_entry_point": ...})`，参考 [cartpole/__init__.py](https://github.com/isaac-sim/IsaacLab/blob/main/source/isaaclab_tasks/isaaclab_tasks/manager_based/classic/cartpole/__init__.py)。

### 步骤 4：启动训练

与流程一相同，指定新注册的 `--task` ID。

## 流程四：策略导出与部署

- **仿真内评估**：RL 用 `rsl_rl/play.py`；IL 用 [robomimic/play.py](https://github.com/isaac-sim/IsaacLab/blob/main/scripts/imitation_learning/robomimic/play.py)（见官方 teleop / imitation 文档）。
- **导出**：PyTorch checkpoint 可进一步导出 ONNX 等格式，需按具体部署目标自行编写转换脚本。
- **真机 / ROS**：Isaac Lab 提供 [Docker ROS 2 扩展](https://github.com/isaac-sim/IsaacLab/blob/main/docs/source/deployment/docker.rst) 等部署相关文档；真机推理节点需自行对接。

## 关键注意事项

- 仿真须在 Isaac Sim 进程内运行，通过 `isaaclab.sh` / `isaaclab.bat` 注入环境变量。
- 大规模 RL 训练建议使用 `--headless`。
- 自定义任务时，先复制结构相近的现有任务目录再修改。
- Mimic 环境 ID（`*-Mimic-v0`）用于标注与数据生成；BC 训练通常用对应的非 Mimic 任务 ID。
