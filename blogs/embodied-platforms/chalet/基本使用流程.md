## 1. 选型：Binary vs 源码

| 路径 | 适用 | 依据 |
|------|------|------|
| **官方 Binary（推荐）** | 复现 CHAI、WebGL 众包、CIFF 实验 | [README.md L7–8](../code/CHALET-main/README.md) |
| **GitHub 源码** | 改 Unity 场景/交互逻辑；需 Asset Store + 修改资产 | [README.md L31–33](../code/CHALET-main/README.md) |
| **仅读数据** | 下载 JSON 语料，不跑仿真 | Misra-EMNLP-2018 数据包 |

研究复现 **优先 binary**；源码构建成本高且 Wiki 标注为 unstable。

## 2. 下载与目录结构

### 2.1 CHALET v0.1 Binary

1. 打开 [clic.nlp.cornell.edu/resources/CHALET/](http://clic.nlp.cornell.edu/resources/CHALET/)  
2. 下载 Version 0.1 对应平台的 build（含 WebGL）  
3. WebGL 测试：将 build 放入 `src/chalet/`（Wiki）

### 2.2 CHAI / LANI 数据 + 仿真器 bundle

CIFF 统一包：

```
http://clic.nlp.cornell.edu/resources/Misra-EMNLP-2018/
```

解压后典型结构（[CIFF README L22–23](../code/CIFF-main/README.md)）：

```
ciff/
├── src/           # CIFF Python 代码（可替换为 ../code/CIFF-main/src/）
├── simulators/    # LANI、CHAI（CHALET）Unity build
├── data/          # train/dev/test JSON
└── media/         # 辅助资源
```

CHAI 数据 JSON 字段解析见 [dataset_parser.py](../code/CIFF-main/src/dataset_agreement_house/dataset_parser.py)（`Dataset` → `Instruction`, `House`, `Trajectory`, `ID`）。

## 3. WebGL Standalone（浏览器可视化）

Wiki 步骤摘要：

1. 下载 CHALET WebGL build → 放到 `src/chalet/`  
2. 用 **`src/webgl_standalone_test.html`** 打开（**Firefox** 可直接试）  
3. **Chrome** 通常需本地 HTTP server  
4. WebGL build 约 **386 MB**（[src/README.md L6](../code/CHALET-main/src/README.md)）

用途：**可视化房屋**、AMT 众包采集（Standalone 模式录轨迹）。

> ML 训练请走 **CIFF + Linux build**（见 §4），而非 WebGL Simulator（Wiki 曾标 Coming Soon）。

## 4. 通过 CIFF 跑 CHAI 实验（推荐）

[CIFF](https://github.com/lil-lab/ciff) 封装 CHALET socket 通信，避免手写客户端。

### 4.1 安装

```bash
git clone https://github.com/lil-lab/ciff.git
cd ciff
# 下载 Misra-EMNLP-2018 的 simulators + data，解压到 ciff 根目录
export PYTHONPATH=$PYTHONPATH:./src/
pip install -r requirements.txt
```

或使用本地快照 `../code/CIFF-main/`。

### 4.2 运行实验

```bash
python3 src/experiments_house/test_stop.py          # STOP baseline
python3 src/experiments_house/test_chaplot_baseline_house.py
python3 src/experiments_house/train_chaplot_baseline_house.py
```

- **domain**：`house` → CHAI / CHALET  
- 实验列表：[CIFF Sample Experiments Wiki](https://github.com/lil-lab/ciff/wiki/Sample-Experiments)  
- CIFF **内部启动** Unity build 并建立 socket（[house_server.py L24–28](../code/CIFF-main/src/server_house/house_server.py)）

`test_stop.py` 读取 `data/house/config.json` 并校验配置键（[validate_setup_house.py L3–11](../code/CIFF-main/src/setup_agreement_house/validate_setup_house.py)），使用 **5 套 house**（L76：`house_ids = [1, 2, 3, 4, 5]`）。

### 4.3 ActionSpace 与配置

CHAI 动作由 config 驱动（[action_space.py](../code/CIFF-main/src/dataset_agreement_house/action_space.py)）：

```python
action_space = ActionSpace(
    config["action_names"],           # e.g. forward, turnleft, turnright, stop
    config["stop_action"],
    config["use_manipulation"],       # True → 展开 32×32 interact
    config["num_manipulation_row"],     # 32
    config["num_manipulation_col"],     # 32
)
```

### 4.4 支持的训练方式

| 类型 | 示例脚本 |
|------|----------|
| Baseline | [test_stop.py](../code/CIFF-main/src/experiments_house/test_stop.py) · [test_randomwalk.py](../code/CIFF-main/src/experiments_house/test_randomwalk.py) · [test_most_frequent.py](../code/CIFF-main/src/experiments_house/test_most_frequent.py) |
| 模型 | [test_chaplot_baseline_house.py](../code/CIFF-main/src/experiments_house/test_chaplot_baseline_house.py) · [train_chaplot_baseline_house.py](../code/CIFF-main/src/experiments_house/train_chaplot_baseline_house.py) |
| 异步 RL | [train_asynchronous_learning.py](../code/CIFF-main/src/experiments_house/train_asynchronous_learning.py) |
| 两阶段 | [train_two_stage_asynchronous_learning.py](../code/CIFF-main/src/experiments_house/train_two_stage_asynchronous_learning.py) |

算法：BC、A3C、REINFORCE；配置通过 JSON + TensorBoard。

## 5. Client 模式（Socket API）

### 5.1 Unity 侧

`SocketManager` 在 localhost 建立 TCP 监听（[SocketManager.cs L71–95](../code/CHALET-main/src/Assets/Scripts/API%20stuff/SocketManager.cs)）：

- 默认 `IPAddress.Any` · **port 11000**  
- 接收 ASCII 动作字符串 → `BotController` 指令队列  
- 回传 RGB 图像 + `#` 分隔 meta 字符串  

Bot 动作封装（[Actions.cs L29–34](../code/CHALET-main/src/Assets/Scripts/API%20stuff/Actions.cs)）：`Interact()` → `interact.ShootRay()`。

### 5.2 Python 侧（CIFF HouseServer）

```python
# house_server.py L30–33 — 发送动作并接收观测
action_string = self.action_space.get_action_name(action)
self.connection.send_message(HouseServer.to_byte_arr(action_string))
image = self.connection.receive_image()
message = self.connection.receive_message()
```

Reset 协议：`ok-reset {datapoint_id}`（L83）。Panorama：`panorama` → 6 张图拼接（L100–117）。

### 5.3 返回 meta 字段

| 字段 | 含义 |
|------|------|
| `reward` | 即时 reward（[Rewards.cs](../code/CHALET-main/src/Assets/Scripts/API%20stuff/Rewards.cs) 当前返回 0） |
| `bot-position` / `bot-angles` | Agent 位姿 |
| `navigation-error` | 累计导航误差（SD 相关） |
| `manipulation-accuracy` | 操作准确度（MA 相关） |
| `goal-type` | NAVIGATION / INTERACTION |

## 6. Standalone：人工录制 Demonstration

1. 启动 Standalone / WebGL build  
2. 键鼠控制 agent（`Interact` + 移动脚本）  
3. `DataCollection` 每秒写入 **DIOS**（Data In One Second），事件触发 JSON 序列化（[DataCollection.cs L10–13、L18](../code/CHALET-main/src/Assets/Scripts/Data%20Collection/DataCollection.cs)）  
4. Simulator 模式：`LoadRoom` + Bot Elmer 回放轨迹（[LoadRoom.cs L44–52](../code/CHALET-main/src/Assets/Scripts/SceneLoading/LoadRoom.cs)）  

**Text-To-Traj (T3)**：Ruby on Rails 众包平台，链接 CHALET build 构建 **CHAI**（见 [CHAI语料与评测.md](CHAI语料与评测.md)）。

## 9. 常见问题

| 现象 | 处理 |
|------|------|
| WebGL 黑屏 | 换 Firefox；或 `python -m http.server` 托管 HTML |
| Chrome 跨域 | 勿直接 `file://` 打开 |
| 找不到 Linux build | 从 Misra-EMNLP-2018 包内 `simulators/` 取 CIFF 配套 build |
| 源码缺 mesh | 必须用作者提供的 **修改版** Asset Store 资源 |
| Unity 版本不匹配 | 锁定 **5.4.1** |
| Socket 连不上 | 确认 Unity Client 模式 · 默认 **port 11000**（[SocketManager.cs L71–75](../code/CHALET-main/src/Assets/Scripts/API%20stuff/SocketManager.cs)） |
| 与论文指标不一致 | 确认 CHAI **5 动作 + 32×32 INTERACT**（[action_space.py](../code/CIFF-main/src/dataset_agreement_house/action_space.py)） |
| CIFF unstable | [ciff issues](https://github.com/lil-lab/ciff/issues) · dkm@cs.cornell.edu |
