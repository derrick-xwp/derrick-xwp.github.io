DeepMind Lab 关卡与任务参考

关卡根目录：game_scripts/levels/ · 全局选项：docs/levels.md · DMLab-30：README
本地源码：https://github.com/google-deepmind/lab/blob/main/game_scripts/（153 个 .lua 关卡 + factories）

1. 关卡命名与加载

Python 中 level 参数 = 相对 game_scripts/levels/ 的路径，不含 .lua 后缀：

# 根目录关卡
deepmind_lab.Lab('nav_maze_random_goal_01', ['RGB_INTERLEAVED'])

# 子目录
deepmind_lab.Lab('contributed/dmlab30/explore_goal_locations_small', ['RGBD'])
deepmind_lab.Lab('demos/extra_entities', ['RGB_INTERLEAVED'])

Lua 中通过 Lua API 定义：

  • api:init — 读取 kwargs.opts 配置
  • reward、termination、observation 注册
  • 程序化地图生成 hook

1.1 Factory 与程序化地图

多数关卡不直接写完整 API，而是 require 'factories.*' 返回 createLevelApi()。以随机迷宫为例，factory 在 api:start 里 seed RNG 并随机 goal：

function factory.createLevelApi(kwargs)
  kwargs.scatteredRewardDensity = kwargs.scatteredRewardDensity or 0.1
  kwargs.episodeLengthSeconds = kwargs.episodeLengthSeconds or 600
  local maze = maze_generation.mazeGeneration{entity = kwargs.entityLayer}
  local api = {}
  ...
  function api:start(episode, seed, params)
    random:seed(seed)
    randomMap:seed(seed)
    api._timeRemaining = kwargs.episodeLengthSeconds
    ...
    api._goal = {random:uniformInt(1, height) * 2,
                 random:uniformInt(1, width) * 2}
Factory 路径 用于
factories/random_goal_factory.lua nav_maze_random_goal_*
factories/explore/goal_locations_factory.lua DMLab-30 explore_goal_locations_*
factories/explore/ object_locations、obstructed_goals 等
dmlab.system.map_maker 文本层 → BSP/PK3（C++ + Lua）

2. 内置核心关卡

位于 game_scripts/levels/*.lua：

Level 能力
nav_maze_static_01 ~ _03 固定布局迷宫 → 目标点
nav_maze_random_goal_01 ~ _03 随机迷宫 + 随机 goal；难度递增
lt_chasm 窄通道 / 坠落风险
lt_hallway_slope 坡度走廊
lt_horseshoe_color 颜色线索导航
lt_space_bounce_hard 低重力平台跳跃
seekavoid_arena_01 追逐-躲避
stairway_to_melon 到达/收集 melons

demos/、tests/ 用于 smoke test 与 API 验证（如 tests/empty_room_test）。

3. DMLab-30 完整列表

路径前缀：contributed/dmlab30/（本地 game_scripts/levels/contributed/dmlab30/ 含 30 个环境 Lua + 详细 README）
加载示例：contributed/dmlab30/rooms_watermaze

多数任务观测：RGBD + 部分 language（INSTR）。

3.1 Rooms（5）

Level 任务
rooms_collect_good_objects_train / _test 收集「好」物体、避「坏」物体；train/test 物体×环境组合 hold-out（DARLA 等）
rooms_exploit_deferred_effects_train / _test 延迟效应：拾取特殊物体 unlock 后续 reward
rooms_select_nonmatching_object 选择与展示物 不匹配 的对象（+10 vs -10）
rooms_watermaze Morris water maze 式：找隐藏平台，测 episodic memory
rooms_keys_doors_puzzle 彩色钥匙-门 规划 puzzle；顺序错误可达不了 goal

3.2 Language（4）

基于 Hermann et al. 2017 地面语言：

Level 任务
language_select_described_object 按描述选物体
language_select_located_object 「Pick the red object in the blue room」
language_execute_random_task 7 种任务类型随机
language_answer_quantitative_question 是非/计数问题（选白/黑球回答）

3.3 LaserTag（4）

Level 对手 地图
lasertag_one_opponent_small 1 bot 小
lasertag_three_opponents_small 3 bots 小
lasertag_one_opponent_large 1 bot 大
lasertag_three_opponents_large 3 bots 大

程序化.gadget/地图；考验 adaptation。

3.4 NatLab（3）

蘑菇采集 自然地形：

Level 记忆类型
natlab_fixed_large_map 长期记忆 — 大地图，蘑菇不重生
natlab_varying_map_regrowth 短期 — 小随机图，~1 分钟再生
natlab_varying_map_randomized 随机中等地图，蘑菇位置随机

3.5 SkyMaze（2）

Level 任务
skymaze_irreversible_path_hard 不可逆路径 — 禁用 jump，需规划避免困在低平台
skymaze_irreversible_path_varied 随机难度变体

3.6 PsychLab（4）

Leibo et al. 2018 Psychlab：

Level 心理学范式
psychlab_arbitrary_visuomotor_mapping 图像→动作 arbitrary mapping
psychlab_continuous_recognition 连续识别（是否见过）
psychlab_sequential_comparison 两图是否相同（可变 delay）
psychlab_visual_search 集合中是否存在粉色 T

3.7 Explore（8）

程序化迷宫 + 主题随机；建议 level_cache：

Level 任务
explore_object_locations_small / _large 收集 apple；收完 reset
explore_obstructed_goals_small / _large 找 goal + 随机开关门
explore_goal_locations_small / _large 纯导航到 goal；经典记忆基准
explore_object_rewards_few / _many 收集正/负 reward 物体类别

4. Psychlab Memory Suite

contributed/psychlab/memory_suite_01/ 扩展 explore_goal_locations 的训练/评测 split：

变体 用途
explore_goal_locations_train_small / _large 训练地图规模
explore_goal_locations_holdout_small / _large hold-out 评测
explore_goal_locations_interpolate 插值泛化
explore_goal_locations_extrapolate 外推泛化
explore_goal_locations_holdout_interpolate / _extrapolate 组合 hold-out

配合 dm_memorytasks 共 13 项记忆任务 研究。

5. 观测与动作按任务选型

任务类型 推荐 observations 备注
纯视觉 RL RGB_INTERLEAVED 或 RGBD 84×84 或 64×64 常见
语言 grounding RGBD + INSTR 读 env.observations()['INSTR']
分析导航 + VEL.TRANS, VEL.ROT 非 agent 可用特权
调试 DEBUG.POS.TRANS 仅 analysis，非公平 benchmark
LaserTag RGBD + FIRE/JUMP 启用 gadget 时加 config flags

动作向量长度 = len(env.action_spec())，通常 7；Skymaze 等关卡内部将 JUMP 置为 NOOP。

6. 标准 config 与 hold-out

config = {
    'episodeLengthSeconds': '120',
    'allowHoldOutLevels': 'true',  # 字符串形式
    'logLevel': 'WARNING',
}

rooms_collect_good_objects_test 等仅在 allow hold-out 时加载。

7. 自定义关卡（开发者）

  1. 在 game_scripts/levels/my_task.lua 编写 Lua（可参考 nav_maze_random_goal_01.lua）
  2. 若需新 geometry：Quake .map → q3map2 → .bsp → PK3
  3. Bazel 重新打包或 pip rebuild
  4. 文档：developers/

Lua 可注册 custom observations 与 events（env.events() 返回）。
