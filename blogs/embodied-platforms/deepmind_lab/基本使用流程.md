## 1. 环境要求

| 项目 | 说明 |
|------|------|
| **OS** | **Linux** 为主（Debian 9+ / Ubuntu 16.04+ 文档验证）；macOS/Windows 非官方重点 |
| **编译器** | 支持 **C++17** 的 GCC/Clang |
| **构建** | [Bazel](https://docs.bazel.build/versions/master/install.html) |
| **Python** | 2 或 3（默认 **PY3**）；需系统已装 **NumPy** |
| **图形** | Headless：**OSMesa** 或 **EGL**；可视化：SDL/GLX |

## 3. 流程 A：Bazel 开发构建（推荐入门）

[`BUILD`](https://github.com/google-deepmind/lab/blob/master/BUILD) 中主要目标：

| Bazel 目标 | 产物 / 用途 |
|------------|-------------|
| `//:deepmind_lab.so` | Python C 扩展（[`python/dmlab_module.c`](https://github.com/google-deepmind/lab/blob/master/python/dmlab_module.c)） |
| `//:python_random_agent` | 入口 [`python/random_agent.py`](https://github.com/google-deepmind/lab/blob/master/python/random_agent.py) |
| `:game` | C 可执行体，人类试玩 / 观测调试 |

cd lab

# 构建 Python 扩展

# 运行单元测试

bazel run -c opt //:python_random_agent -- \
  --level_name=nav_maze_random_goal_01 \
  --width=84 --height=84

### 3.1 无头训练（OSMesa / EGL）

构建时指定 graphics backend：

```bash
# 常见：software renderer → OSMesa
bazel build -c opt --define graphics=osmesa_or_egl //:deepmind_lab.so
```

Python 侧：

```python
env = deepmind_lab.Lab(level, ['RGB_INTERLEAVED'], renderer='software')
```

`renderer='hardware'` 使用 EGL（需 GPU/驱动）。

## 5. 最小 Python 训练循环

```python
import deepmind_lab
import numpy as np

LEVEL = 'demos/extra_entities'
OBS = ['RGB_INTERLEAVED']

lab = deepmind_lab.Lab(
    LEVEL, OBS,
    config={'fps': '30', 'width': '84', 'height': '84'},
    renderer='software',
)

def random_action(spec):
    a = np.zeros(len(spec), dtype=np.intc)
    for i, dim in enumerate(spec):
        a[i] = np.random.randint(dim['min'], dim['max'] + 1)
    return a

total_reward = 0.0
lab.reset(seed=1)
spec = lab.action_spec()

while lab.is_running():
    total_reward += lab.step(random_action(spec))

print('episode reward:', total_reward)
lab.close()
```

PIP README 中 `demos/extra_entities` 前方 4 个 apple，随机前进约 **100 步 reward ≈ 4.0**。

## 6. Level Cache（程序化关卡加速）

C API 定义 cache 回调（[`level_cache_types.h`](https://github.com/google-deepmind/lab/blob/master/public/level_cache_types.h)）；Python 侧传入带 **`fetch` / `write`** 方法的对象。官方测试用例：

```42:50:embodied-platforms/code/lab-master/python/tests/level_cache_test.py
  def _create_environment(self, level_cache):
    return deepmind_lab.Lab(
        level='contributed/dmlab30/explore_goal_locations_small',
        observations=['RGB_INTERLEAVED'],
        config={
            'width': '96',
            'height': '72',
        },
        level_cache=level_cache)
```

对 `contributed/dmlab30/explore_goal_locations_small` 等 **每 episode 生成新 BSP** 的关卡，推荐实现：

```python
import os, shutil

class LevelCache(object):
    def __init__(self, cache_dir):
        self._cache_dir = cache_dir
        os.makedirs(cache_dir, exist_ok=True)

    def fetch(self, key, pk3_path):
        path = os.path.join(self._cache_dir, key)
        if os.path.isfile(path):
            shutil.copyfile(path, pk3_path)
            return True
        return False

    def write(self, key, pk3_path):
        path = os.path.join(self._cache_dir, key)
        if not os.path.isfile(path):
            shutil.copyfile(pk3_path, path)

env = deepmind_lab.Lab(
    'contributed/dmlab30/explore_goal_locations_small',
    ['RGBD'],
    level_cache=LevelCache('/tmp/dmlab_level_cache'),
)
```

## 10. 常见问题

| 现象 | 处理 |
|------|------|
| Bazel 找不到 Python/NumPy | 安装 `python3-dev python3-numpy`；或设置 `PYTHON_BIN_PATH` |
| 无 DISPLAY 崩溃 | `renderer='software'` + OSMesa 构建 |
| EGL 失败 | 检查 NVIDIA 驱动；或改 OSMesa |
| `import deepmind_lab` 失败 | 确认 `deepmind_lab.so` 在 `PYTHONPATH` 或已 pip install |
| NumPy ABI 不匹配 | PIP 包与 runtime NumPy 版本一致；重建 wheel |
| macOS 构建失败 | 官方主要支持 Linux；考虑 Docker |
| 改 Lua 不生效 | 重新 `bazel build` 或 rebuild pip package |
| C++17 错误 | 升级 GCC（2022 起 Lab 要求 C++17） |

Issue：[github.com/google-deepmind/lab/issues](https://github.com/google-deepmind/lab/issues)
