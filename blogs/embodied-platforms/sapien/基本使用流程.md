# SAPIEN / ManiSkill 基本使用流程

> 基于 [Installation](https://maniskill.readthedocs.io/en/latest/user_guide/getting_started/installation.html) · [Quickstart](https://maniskill.readthedocs.io/en/latest/user_guide/getting_started/quickstart.html)

> 平台介绍：[介绍.md](介绍.md)

## 1. 系统要求

| 项目 | 要求 | 源码依据 |
|------|------|----------|
| **推荐 OS** | **Linux + NVIDIA GPU** | [ManiSkill README.md L56](../code/ManiSkill-main/README.md) |
| **渲染** | **Vulkan**（`libvulkan1`）；无 Vulkan 则 **仅能 state 仿真** | ManiSkill 安装文档 |
| **GPU 仿真** | 仅 **Linux NVIDIA**（Windows/macOS 不支持 GPU PhysX） | [backend.py L58–70](../code/ManiSkill-main/mani_skill/envs/utils/system/backend.py) |
| **Python** | 3.8+；**PyTorch** 与 CUDA 版本匹配 | [setup.py](../code/ManiSkill-main/setup.py) |

WSL：**无渲染**；仅 CPU sim（[README.md L61](../code/ManiSkill-main/README.md)）。

macOS 下 ManiSkill 会强制 `render_backend=sapien_cpu`（[backend.py L73–78](../code/ManiSkill-main/mani_skill/envs/utils/system/backend.py)）。

## 2. 安装

### 2.1 pip（推荐）

官方 README 给出的最简安装（[README.md L32–37](../code/ManiSkill-main/README.md)）：

```bash
pip install --upgrade mani_skill torch
```

每日构建：

```bash
pip install mani_skill-nightly torch
```

SAPIEN 也可单独安装（[readme.md L9–12](../code/SAPIEN-master/readme.md)）：

```bash
pip install sapien
```

### 2.2 源码（改 ManiSkill / 贡献）

```bash
git clone https://github.com/haosulab/ManiSkill.git
cd ManiSkill
pip install -e .
```

SAPIEN 随 `mani_skill` 依赖自动安装；单独开发引擎：

```bash
git clone https://github.com/haosulab/SAPIEN.git
# 见 SAPIEN docker/Dockerfile 与 scripts/docker_build_wheels.sh
```

**从源码构建 SAPIEN wheel**（高级用户）：

1. 初始化子模块：`git submodule update --init --recursive`（[readme.md L191](../code/SAPIEN-master/readme.md)）  
2. Docker 构建（推荐）：`./scripts/docker_build_wheels.sh` · [docker/Dockerfile](../code/SAPIEN-master/docker/Dockerfile)  
3. 本地构建：`python setup.py bdist_wheel`（需按 Dockerfile 配置全部依赖）

### 2.3 Docker

```bash
docker pull maniskill/base
```

无显示器服务器上 SAPIEN 仅需 `libegl1` 和 `libxext6`；NVIDIA Docker 需设置（[readme.md L24–31](../code/SAPIEN-master/readme.md)）：

```dockerfile
ENV NVIDIA_DRIVER_CAPABILITIES graphics,utility,compute
```

### 2.4 环境变量

```bash
export MS_ASSET_DIR=~/.maniskill/data          # 资产根目录（默认 ~/.maniskill/data）
export MS_SKIP_ASSET_DOWNLOAD_PROMPT=1       # 跳过交互式下载提示
```

## 3. 安装 Vulkan（Linux）

```bash
sudo apt-get install libvulkan1 vulkan-tools
vulkaninfo   # 应列出 GPU
```

若 `vulkaninfo` 失败，按 [Installation 文档](https://maniskill.readthedocs.io/en/latest/user_guide/getting_started/installation.html) 创建：

- `/usr/share/vulkan/icd.d/nvidia_icd.json`
- `/usr/share/glvnd/egl_vendor.d/10_nvidia.json`

常见错误：

| 错误 | 处理 |
|------|------|
| `ErrorInitializationFailed` | 重装 `nvidia-driver-xxx`（非 server 包） |
| `Some required Vulkan extension is not present` | 同上 + icd 文件 |
| Segfault | 驱动/Vulkan 配置 |

**macOS**：见文档 [MacOS Installation](https://maniskill.readthedocs.io/en/latest/user_guide/getting_started/macos_installation.html)（无 GPU sim）。

## 5. 最小 Gymnasium 循环

与 [PickCubeEnv](../code/ManiSkill-main/mani_skill/envs/tasks/tabletop/pick_cube.py) 配套的 smoke test：

```python
import gymnasium as gym
import mani_skill.envs
import torch

env = gym.make(
    "PickCube-v1",
    num_envs=1,
    obs_mode="state",
    control_mode="pd_joint_delta_pos",
    render_mode="human",   # 或 None / "rgb_array"
)

obs, info = env.reset(seed=0)

for _ in range(200):
    action = env.action_space.sample()
    obs, reward, terminated, truncated, info = env.step(action)
    if terminated.any() if hasattr(terminated, "any") else terminated:
        obs, info = env.reset()

env.close()
```

`num_envs=1` 时 `sim_backend="auto"` 选用 **PhysX CPU**（[sapien_env.py L95–96](../code/ManiSkill-main/mani_skill/envs/sapien_env.py)）。

## 6. GPU 并行仿真

```python
env = gym.make(
    "PickCube-v1",
    num_envs=1024,              # >1 自动启用 GPU PhysX
    obs_mode="state",
    control_mode="pd_joint_delta_pos",
)

obs, info = env.reset()
# obs 等为 torch.Tensor，device=cuda:0
```

Backend 解析（[backend.py L52–70](../code/ManiSkill-main/mani_skill/envs/utils/system/backend.py)）：

| `sim_backend` 输入 | 实际后端 | 设备 |
|--------------------|----------|------|
| `"auto"` + `num_envs>1` | `physx_cuda` | `cuda` |
| `"physx_cpu"` | CPU PhysX | `cpu` |
| `"physx_cuda:n"` | GPU PhysX | `cuda:n` |

Benchmark 脚本（[gpu_sim.py L19–67](../code/ManiSkill-main/mani_skill/examples/benchmarking/gpu_sim.py)）：

```bash
python -m mani_skill.examples.benchmarking.gpu_sim --num-envs=1024
python -m mani_skill.examples.benchmarking.gpu_sim -e PushCube-v1 -o rgb+depth+segmentation -n 64
```

多卡：

```bash
export CUDA_VISIBLE_DEVICES=1
# 代码中仍显示 cuda:0，实际为物理 GPU 1
```

强制 backend：

```python
gym.make("PickCube-v1", sim_backend="physx_cuda:0", num_envs=512)
```

## 7. 视觉观测与渲染

```python
env = gym.make(
    "PickCube-v1",
    num_envs=4,
    obs_mode="rgb+depth+segmentation",
    control_mode="pd_ee_delta_pose",
    render_mode="sensors",    # 或 "human"
    shader_dir="minimal",     # 最快；"rt" 为光追
)
```

底层批量渲染由 SAPIEN `BatchedCamera` + Vulkan-CUDA interop 实现（[batched_render_system.cpp](../code/SAPIEN-master/src/sapien_renderer/batched_render_system.cpp)）。

注意：**parallel rendering + GUI viewer** 不兼容；`parallel_in_single_scene=False` 时用 state 或离屏渲染（[sapien_env.py L111–113](../code/ManiSkill-main/mani_skill/envs/sapien_env.py)）。

可视化示例：

```bash
python -m mani_skill.examples.demo_vis_pcd -e PushCube-v1
python -m mani_skill.examples.demo_vis_segmentation -e PushCube-v1
python -m mani_skill.examples.demo_vis_textures -e PickCube-v1
```

## 12. 常见问题

| 现象 | 处理 |
|------|------|
| 资产下载失败 | 检查网络；手动设 `MS_ASSET_DIR` |
| GPU OOM | 减小 `num_envs`；调 `GPUMemoryConfig` |
| Windows 无 GPU sim | 预期行为；用 Linux 或 `num_envs=1` CPU |
| `obs_mode=rgbd` 无图 | 安装 Vulkan；headless 用 `render_mode="sensors"` |
| ManiSkill2 脚本报错 | 换 **ManiSkill 3** API 或 checkout **v0.5.3** |
| 卸载残留 | `pip uninstall mani-skill` + 删 `~/.maniskill` + 包内 cache mesh |
| macOS 渲染慢 | 强制 CPU 渲染（[backend.py L73–78](../code/ManiSkill-main/mani_skill/envs/utils/system/backend.py)） |

Issues：https://github.com/haosulab/ManiSkill/issues
