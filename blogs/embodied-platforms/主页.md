## 4. 按动作粒度与 API 风格

| 类型 | 代表平台 | 动作形式 | 典型用途 |
|------|----------|----------|----------|
| **离散高层** | VirtualHome、CHALET | `[Walk]` / `GoTo` / 程序行 | 规划、IL、语言 grounding |
| **离散 mid** | AI2-THOR、BEHAVIOR | `step(action="OpenObject")`、BDDL 谓词 | 交互推理、状态跟踪 |
| **连续低层** | ManiSkill、Isaac、VRKitchen Tool | 关节/末端 6-DoF+ | RL、模仿学习 |
| **命令式底层** | TDW | 200+ JSON `$type` 命令 | 多模态采集、自定义物理实验 |
| **导航专用** | Habitat、DMLab | 转向+前进 或 速度指令 | 大规模 RL |

## 7. 决策流程

```mermaid
flowchart TD
    Start([选定研究问题]) --> Q1{需要物理驱动<br/>音频?}
    Q1 -->|是| TDW[TDW]
    Q1 -->|否| Q2{RL 吞吐<br/>优先?}
    Q2 -->|是| Q2a{操作还是导航?}
    Q2a -->|操作| MS[ManiSkill / Isaac]
    Q2a -->|导航| Hab[Habitat / DMLab]
    Q2 -->|否| Q3{语言/程序<br/>高层任务?}
    Q3 -->|是| VH[VirtualHome / CHALET / BDDL]
    Q3 -->|否| Q4{长 horizon<br/>真实家务?}
    Q4 -->|是| B1K[BEHAVIOR-1K]
```

## 8. 任务类型 × 平台推荐（速查）
