iGibson 基本使用流程

源码根目录：StanfordVL/iGibson · 官方文档：Installation · Dataset · Environments
本地拉取：cd embodied-platforms/repos && bash fetch_repos.sh igibson（可选，见 repos/README.md）
同目录延伸阅读：介绍.md · 场景任务与API参考.md

概述

iGibson 的使用遵循「安装 → 下载资产/数据集 → YAML 配置 → iGibsonEnv 或 Simulator API → 训练/评测」管线。最快路径是 pip + demo 数据；交互任务需 ig_dataset（表单 + igibson.key）。

1. 系统要求

平台 要求
Linux（推荐） Ubuntu 16.04+；NVIDIA GPU VRAM > 6GB；driver ≥ 384；CUDA ≥ 9
Windows Win10 + VS2017 + 同上 GPU
macOS 可运行；PBR 不支持；部分测试需 NVIDIA

通用：CMake ≥ 2.8.12（pip install cmake）、g++、libegl-dev、Python 3.8（conda 推荐）。

Simulator 在 macOS 上对 headless_tensor 与 use_pb_gui 有平台限制（simulator.py L98–106）。

2. 安装方式（三选一）

2.1 pip（最快试用）

conda create -n igibson python=3.8 -y
conda activate igibson

pip install igibson   # 约 4 分钟

python -m igibson.examples.environments.env_nonint_example

入口脚本：env_nonint_example.py

2.2 源码 editable（改代码 / 复现论文）

git clone https://github.com/StanfordVL/iGibson.git --recursive
cd iGibson

conda create -n igibson python=3.8 -y
conda activate igibson

# 若已有系统 pybullet，需换 SVL fork：
pip uninstall pybullet -y
pip install pybullet-svl

pip install -e .

2.3 Docker

# 无 GUI
docker pull igibson/igibson:latest

# 带 VNC GUI
docker pull igibson/igibson-vnc:latest

本地构建：docker/igibson/build.sh 或 igibson-vnc/build.sh。需 Docker ≥ 19（GPU 支持）。

3. 数据与资产下载

3.1 配置数据路径

默认路径见 igibson/global_config.yaml：

assets_path: data/assets
g_dataset_path: data/g_dataset      # Gibson 静态
ig_dataset_path: data/ig_dataset    # 15 交互场景 + 物体
threedfront_dataset_path: data/threedfront_dataset
cubicasa_dataset_path: data/cubicasa_dataset
key_path: data/igibson.key

修改路径：

python -m igibson.utils.assets_utils --change_data_path

实现见 igibson/utils/assets_utils.py。

3.2 下载步骤

步骤 命令 / 动作
1. 机器人等小资产 python -m igibson.utils.assets_utils --download_assets
2. 快速 demo（Rs 静态） python -m igibson.utils.assets_utils --download_demo_data
3. iGibson 交互包 填表 → 收 igibson.key 放 data 目录 → 下载 tar → tar -xvf ig_dataset.tar.gz -C .../igibson/data
4. Gibson v2 全量 表单 URL → python -m igibson.utils.assets_utils --download_dataset URL

交互任务需：ig_dataset（场景 + BEHAVIOR 物体）。纯 Gibson 导航可只用 g_dataset 或 demo。

4. 验证安装

python -c "import igibson; print('ok')"

完整测试（Linux + NVIDIA）：

cd iGibson && pytest

测试目录：igibson/tests/

5. 流程 A：静态 Gibson 导航（无需 ig_dataset）

python -m igibson.examples.environments.env_nonint_example
  • 使用 turtlebot_static_nav.yaml + Rs（非交互 mesh）
  • 自动 download_assets + download_demo_data
  • Mac：config 中 texture_scale: 0.5；关闭 PBR/shadow

6. 流程 B：交互场景 Rs_int

官方示例 env_int_example.py 完整流程：

# 需已下载 ig_dataset
python -m igibson.examples.environments.env_int_example

核心代码逻辑（摘自官方示例）：

import yaml
import igibson
from igibson.envs.igibson_env import iGibsonEnv
from igibson.utils.assets_utils import download_assets

download_assets()
config_path = igibson.configs_path + "/turtlebot_nav.yaml"
with open(config_path) as f:
    config = yaml.safe_load(f)

config["enable_shadow"] = True
config["enable_pbr"] = True
# config["load_object_categories"] = []  # 仅加载建筑，加速

env = iGibsonEnv(config_file=config, mode="headless")
obs = env.reset()
# ... step loop ...
env.close()
  • 配置模板：igibson/configs/turtlebot_nav.yaml
  • scene_id: Rs_int；物体可推/抓/开门
  • should_open_all_doors: true（导航任务常用）

加速加载（仅建筑、无家具）：

load_object_categories: []

7. 流程 C：YAML 自定义训练

import os
import yaml
import igibson
from igibson.envs.igibson_env import iGibsonEnv

config_path = os.path.join(igibson.configs_path, "fetch_nav.yaml")
with open(config_path) as f:
    cfg = yaml.safe_load(f)

cfg.update({
    "scene": "igibson",
    "scene_id": "Beechwood_0_int",
    "task": "interactive_nav_random",
    "should_open_all_doors": True,
    "output": ["rgb", "depth", "scan", "task_obs"],
    "mode": "headless",
})

env = iGibsonEnv(config_file=cfg, mode="headless")

obs = env.reset()
for t in range(500):
    action = env.action_space.sample()
    obs, reward, done, info = env.step(action)
    if done:
        obs = env.reset()
env.close()

obs["rgb"]：H×W×3；obs["scan"]：LiDAR；obs["task_obs"]：目标/本体。观测键由 load_observation_space() 构建（igibson_env.py L118+）。

更多 config 模板：igibson/configs/（fetch_nav.yaml、behavior_robot.yaml 等）。

8. 直接使用 Simulator API

不经过 Gym，适合 debug 场景/路径：

python -m igibson.examples.scenes.ig_scene_selector
python -m igibson.examples.scenes.g_scene_selector      # Gibson 静态
python -m igibson.examples.robots.robot_control_example
python -m igibson.examples.robots.motion_planning_example
python -m igibson.examples.robots.all_robots_visualizer

示例索引：igibson/examples/

9. Headless 与渲染模式

mode 说明 源码
headless 无窗口；集群训练 SimulatorMode
headless_tensor GPU tensor 渲染（Linux） simulator.py L186–194
gui_interactive 本地 GUI + 键盘交互
iggui iGibson 定制 GUI

iGibsonEnv(..., mode="headless") 或 Simulator(mode=...)。

无 CUDA 时：修改 igibson/render/CMakeLists.txt 中 USE_CUDA=False（失去 render-to-GPU-tensor）。

10. 域随机化配置

对应 iGibsonEnv.randomize_domain()：

texture_randomization_freq: 10    # 每 10 episode 随机材质
object_randomization_freq: null   # 关闭；或 1000（较慢）
object_randomization_idx: 3       # 使用预验证布局 0–9

11. 迁移至 OmniGibson（BEHAVIOR-1K）

若需 BDDL-1K 长 horizon 家务任务，应使用 OmniGibson。本地已有 BEHAVIOR-1K 快照，安装见 BEHAVIOR 基本使用流程。

Quickstart 对照（OmniGibson 官方 quickstart.md）：

import omnigibson as og

cfg = dict()
cfg["scene"] = {"type": "InteractiveTraversableScene", "scene_model": "Rs_int"}
cfg["robots"] = [{"type": "Turtlebot", "obs_modalities": ["rgb", "depth", "scan"]}]
cfg["task"] = {"type": "PointNavigationTask"}

env = og.Environment(cfg)
obs, info = env.reset()
# ...
env.close()

YAML 导航配置对照：iGibson turtlebot_nav.yaml ↔ 本地 OmniGibson turtlebot_nav.yaml。

12. 常见问题

现象 处理
pip install -e . 失败 卸载官方 pybullet，装 pybullet-svl
找不到场景 检查 ig_dataset_path 与 igibson.key（global_config.yaml）
Mac segfault 降低 texture_scale；关 PBR（见 env_int_example.py）
CUDA/nvcc 找不到 export PATH=/usr/local/cuda-11.1/bin:$PATH
加载极慢 load_object_categories: [] 或按 room/category 过滤
无 ig_dataset 交互示例失败；先用 env_nonint_example
VR / BehaviorRobot 见 iGibson 2.0 文档与 behavior.stanford.edu

Issues：https://github.com/StanfordVL/iGibson/issues
