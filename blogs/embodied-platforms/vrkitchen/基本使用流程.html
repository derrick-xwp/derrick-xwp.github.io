VRKitchen 基本使用流程

基于 xfgao/VRKitchen README · 本地源码 https://github.com/xfgao/VRKitchen/blob/master/
论文 §3.4–3.5 · 项目站

1. 系统要求

项 要求 源码依据
OS Ubuntu 16.04 README.md
Python 2.7.12 同上
GPU NVIDIA 独显推荐 UE4 渲染 + RL 默认 .cuda()
VR（可选） Oculus Rift + Touch 示教采集（UE4 内）

requirements.txt 锁定 PyTorch 0.4 时代栈：

numpy==1.16.2
torch==0.4.1
gym==0.12.5
pyrapidjson==0.5.1
opencv-python==4.0.0.21
...

复现论文建议 conda/venv 隔离；task_tool.py / task_dish/*.py 中状态张量直接 .cuda()，无 GPU 需改 CPU 或 mock。

2. 安装

2.1 克隆与 Python 依赖

git clone https://github.com/xfgao/VRKitchen.git
cd VRKitchen
pip install -r requirements.txt

本地已有一份完整树：https://github.com/xfgao/VRKitchen/blob/master/（无需再 clone 即可读源码）。

2.2 下载 UE4 可执行文件

  1. VRKitchen-v0.1.0.zip
  2. 解压到仓库 Binaries/

DiscreteAgent 启动 UE 时路径为：

./Binaries/{task_type}/VRInteractPlatform/Binaries/Linux/VRInteractPlatform

其中 task_type 为 PrepareDish（备菜）或 ToolUse（工具任务），见 DiscreteAgent.py L31。

注意：构造函数内会 subprocess.Popen 拉起 UE 进程；若你 手动 先启动 release 二进制，需确保端口 10120/10121 未被占用。

2.3 启动顺序

推荐：先确保 UE4 在跑，再执行 Python RL/API 脚本。

# 1. 启动 UE4（路径以 zip 内实际文件为准）
./Binaries/PrepareDish/VRInteractPlatform/Binaries/Linux/VRInteractPlatform   # 备菜
# 或 ToolUse 目录下同名可执行文件

# 2. Script 目录
cd VRKitchen/Script
python example_dish.py    # 备菜 RL
python example_tool.py    # 工具连续 RL

连接失败时见 socketClient.py L31：Can not connect to ('127.0.0.1', 10120)。

3. Python–UE4 通信

DiscreteAgent 默认端点：

            client_endpoint=("127.0.0.1", 10120), \
            server_endpoint=("127.0.0.1", 10121)):
组件 文件 说明
Client socketClient.py TCP 发送 JSON 行（rapidjson.dumps + \n）
Server socketServer.py 接收大块 buffer（RGB 用 \nEND OF FILE\n 分隔）
状态同步 send_tf() / receive_msg() 发送 Agent 姿态；接收 Objects/RGB/Reward/Done

start() 流程：server.listen() → client.connect() → send_tf() 循环重试至多 50 次（retry_num）。

4. 复现论文实验

4.1 备菜（离散 RL）

example_dish.py 注册四类任务：

TaskMap = {"Cut": Cut, "Sandwich": Sandwich, "Stew": Stew, "Juice": Juice}
cd Script
python example_dish.py

默认 ppo_dish("Sandwich", 1000)。切换任务：

task_name = "Juice"   # Cut / Sandwich / Stew / Juice
ppo_dish(task_name, max_steps)
# dqn_dish(...) / a2c_dish(...)

PPO 配置要点（与论文一致）：state_dim=84、NatureConvBody、rollout_length=3000、discount=0.95；checkpoint 路径 data/model-{algo}-{task}-vanilla.bin。

4.2 工具使用（连续 RL）

example_tool.py：

TaskMap = {"CutCarrot":CutCarrot, "PourWater":PourWater, "GetWater":GetWater, "OpenCan":OpenCan, "PeelKiwi":PeelKiwi}
cd Script
python example_tool.py

默认 ddpg_pixel("CutCarrot", 50)，action_dim=7。切换：

task_name = "PourWater"
ddpg_pixel(task_name, max_steps)
# ppo_continuous / a2c_continuous

DDPG 使用 DeterministicActorCriticNet + OU noise（random_process_fn），target_network_mix=1e-3。

4.3 规则测试（无 RL）

task_dish/Juice.py 内 test() 固定 11 步动作序列：

def test():
    task_list = [5,0,2,4,6,1,3,4,6,7,8]
    task_fn = lambda : Juice(frame_skip=1, max_steps=100)
    task = task_fn()
    task.start()
    for a in task_list:
        a,b,c,d = task.step(a)
        print("reward", b)
cd Script
python -m task_dish.Juice

5. 高层备菜 API（非 RL）

api_dish.py 模块级单例 env：

env = DiscreteAgent({"Name":"Agent1", \
            "Actor":{"Loc":{"X":0,"Y":0,"Z":0},\
                "Rot":{"Pitch":0.0,"Yaw":0.0,"Roll":0.0}}, \
            # ... LeftHand / RightHand / Head ...
            "rgb": True, "depth": False, "mask": False,
            "scene": "2"
            }, task_type="PrepareDish"
)

典型脚本（UE4 已启动，在 Script/ 目录）：

from api_dish import GoTo, Take, PlaceTo, Use, Open, env, InitDict

env.start()
InitDict()

GoTo("Fridge")
Open("Fridge")
Take("Tomato")
GoTo("Juicer")
Use("Juicer")

GoTo 调用 env.GoToPos(loc)，坐标来自 tool_pos.py 中 tool_pos[scene][loc]。

6. 观测配置

DiscreteAgent 构造 / init_state 字段：

键 默认 说明
"rgb" True 第一人称 RGB → RL 中 resize 84×84
"depth" False 深度图（receive_msg 读 Depth 段）
"mask" False 实例分割
"scene" "2" 场景 ID；tool_pos 含 "2"、"3" 等

Tool 连续控制：

env.step_tool("ControlRightHand", scale=30, loc=..., rot=..., grab_strength=..., grab_actor="Knife", grab_comp="StaticMeshComponent0")

实现见 DiscreteAgent.step_tool → ControlRightHand()。

7. 目录结构（Script 详解）

路径 说明
DiscreteAgent.py 桥接核心：motor 原语、GoToPos、step/step_tool
api_dish.py 备菜 API + ObjDict + 列表常量
task_dish/ Juice/Stew/Sandwich/Cut Gym 接口
task_tool.py 五类 Tool Use 环境
deep_rl/ Agent、Replay、NatureConvBody
example_dish.py / example_tool.py 论文 benchmark 入口
tool_pos.py 各 scene 的 PosList 世界坐标
data/ 模型 checkpoint（.gitignore，需训练生成）
log/ TensorBoard 日志

9. VR 示教（概念流程）

论文配置：Oculus Rift + Touch；记录双手 3D 位姿/旋转/grab strength（100Hz）；状态含第一人称 RGB。

开源仓库以 Python API + RL 为主；VR 采集集成在 UE4 二进制与 UI 模块。备菜 demo 另提供 Web UI 点选离散原子动作（论文 §6.2）。

10. 常见问题（FAQ）

现象 处理
Can not connect to ('127.0.0.1', 10120) 启动 Binaries 下 UE4；检查 PrepareDish/ToolUse 是否与脚本一致
PyTorch/CUDA 报错 需 torch 0.4.1；或改 task_*.py 中 .cuda() 为 CPU
pip install 失败 Docker / conda 模拟 Ubuntu 16.04 + Py2.7
RL 不收敛 与论文一致；先试 Juice、增大 max_steps
换场景无效 改 env 的 "scene" 并确认 tool_pos.py 有对应键
现代 Python / GPU RL 考虑 VRKitchen 2.0 或 port 通信层

11. 二次开发指引

目标 做法
新备菜任务 仿 task_dish/Juice.py 定义 action_dim、step() 映射
新 Tool 任务 仿 CutCarrot 设置 init_state 与 grab_actor
新原子动作 在 api_dish.py 增加函数，组合 env.MoveToObject / GrabObject 等
新导航点 扩展 tool_pos.py + PosList
UE4 源码 联系作者 / 项目站（release 以二进制为主）
