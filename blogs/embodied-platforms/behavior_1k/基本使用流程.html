BEHAVIOR-1K 基本使用流程

源码根目录：StanfordVL/BEHAVIOR-1K · 本地快照：https://github.com/StanfordVL/BEHAVIOR-1K/blob/main/
官方文档：Installation · Quickstart · Challenge Evaluation
同目录延伸阅读：介绍.md · BDDL与任务体系.md · OmniGibson技术参考.md

概述

BEHAVIOR-1K 的使用遵循「模块化安装 → 验证示例 → 加载 BehaviorTask → Challenge 评测 / JoyLo 采集」管线。Monorepo 通过 setup.sh 统一管理 OmniGibson、BDDL3、数据集与可选组件。

1. 前置条件

项目 要求 官方依据
操作系统 Ubuntu 20.04+ 或 Windows 10+ installation.md
内存 32 GB RAM 及以上 同上
GPU NVIDIA RTX 2070 或更高 同上
显存 8 GB VRAM 及以上 同上
磁盘 数据集 + Isaac Sim 数十 GB
账号 BEHAVIOR 加密数据集需接受许可 --accept-dataset-tos

2. 克隆与模块化安装

git clone https://github.com/StanfordVL/BEHAVIOR-1K.git
cd BEHAVIOR-1K

2.1 推荐：一键 setup（Linux）

setup.sh 支持的 flag（L24–52）：

Flag 作用
--new-env [NAME] 创建 conda 环境（默认 behavior）
--omnigibson 安装 OmniGibson + Isaac Sim（需 --bddl）
--bddl 安装 BDDL3
--dataset 下载 BEHAVIOR 场景/物体 bundle
--eval Challenge 评测依赖（需 --joylo）
--primitives CuRobo motion primitives
--joylo JoyLo 遥操作
--cuda-version X.Y CUDA 版本（默认 12.8）
--accept-conda-tos 等 非交互式安装 
# 核心组件
./setup.sh --new-env --omnigibson --bddl --dataset

# 完整（含评测 + 遥操作 + primitives）
./setup.sh --new-env --omnigibson --bddl --dataset --joylo --eval --primitives

# 非交互式（CI / headless）
./setup.sh --new-env --omnigibson --bddl --dataset \
  --accept-conda-tos --accept-nvidia-eula --accept-dataset-tos

依赖约束（setup.sh L91–94）：--omnigibson 要求 --bddl；--eval 要求 --omnigibson + --joylo。

Windows 使用 setup.ps1，参数类似。

2.2 激活环境

conda activate behavior

首次 import omnigibson 时 Omniverse 初始化可能耗时 约 5 分钟（installation.md 说明为正常现象）。

3. 快速验证：机器人控制示例

官方安装验证命令（installation.md）：

python -m omnigibson.examples.robots.robot_control_example --quickstart

脚本路径：OmniGibson/omnigibson/examples/robots/robot_control_example.py

场景浏览：

python -m omnigibson.examples.scenes.scene_selector

4. 加载 BEHAVIOR 任务（Environment API）

官方 Quickstart 工作流：定义 cfg["scene"] / cfg["robots"] / cfg["task"] → og.Environment(cfg)（quickstart.md）。

import omnigibson as og
from omnigibson.macros import gm

# gm.HEADLESS = True
# import os; os.environ["OMNIGIBSON_GPU_ID"] = "0"

cfg = {
    "scene": {
        "type": "InteractiveTraversableScene",
        "scene_model": "Rs_int",
        "load_object_categories": ["floors", "walls", "ceilings"],
    },
    "robots": [{
        "type": "Fetch",
        "obs_modalities": ["rgb", "depth"],
        "action_normalize": True,
    }],
    "task": {
        "type": "BehaviorTask",
        "activity_name": "assembling_gift_baskets",
        "activity_definition_id": 0,
        "activity_instance_id": 0,
    },
}

env = og.Environment(cfg)
obs, info = env.reset()

for _ in range(100):
    action = env.action_space.sample()
    obs, reward, terminated, truncated, info = env.step(action)
    if terminated or truncated:
        obs, info = env.reset()

env.close()
og.shutdown()

4.1 BehaviorTask 关键字段

源码：behavior_task.py L39–68

字段 说明
activity_name BDDL 活动名；须在 get_behavior_activities() 返回列表中
activity_definition_id 同一活动的不同 BDDL 变体（problem0.bddl 等）
activity_instance_id 预采样布局 ID（online_object_sampling=False 时使用）
online_object_sampling 运行时在线采样初始条件
use_presampled_robot_pose 使用场景 metadata 中的机器人初始位姿

列出全部活动名：

from omnigibson.utils.bddl_utils import get_behavior_activities
print(len(get_behavior_activities()), get_behavior_activities()[:5])

5. 数据集与资产路径

资产 默认位置 说明
OmniGibson robots 等 omnigibson/data/ 未加密，setup 自动下载
BEHAVIOR 场景/物体 数据集 bundle 加密 USD，需 --dataset
场景 state JSON + traversability 与 USD 物体引用配合

官方说明（important_concepts.md L59–69）：BEHAVIOR 物体为加密 USD；OmniGibson assets（机器人等）单独分发、未加密。

若仅做通用机器人仿真（非 BEHAVIOR 任务），可只装 --omnigibson --bddl 而不下载完整 dataset。

6. Challenge 评测流程

6.1 安装评测依赖

./setup.sh --new-env --omnigibson --bddl --dataset --joylo --eval

--eval 依赖 JoyLo 中的 gello 工具（eval.py L15–21 导入 og_teleop_utils）。

6.2 启动 policy 并评测

eval.py 使用 Hydra 配置；Evaluator 类（L66–73）管理 rollout 与 TaskMetric / AgentMetric。

conda activate behavior
export LOG_PATH=/path/to/logs

python OmniGibson/omnigibson/learning/eval.py \
  policy=websocket \
  task.name=turning_on_radio \
  log_path=$LOG_PATH

评测宏（eval.py L47–54）：

  • gm.ENABLE_TRANSITION_RULES = True
  • NUM_EVAL_INSTANCES = 10

6.3 评测配置要点

配置 Standard track Privileged track
观测 RGB + depth + instance seg + proprio 可访问仿真真值
成功 BDDL goal 谓词全部满足 同左
部分分 q_score 新满足的 goal 谓词比例 task_metric.py L34–46

Challenge 机器人 R1Pro 的相机与 action 索引：eval_utils.py。

任务名列表：https://behavior.stanford.edu/challenge/tasks.html

7. 遥操作与数据采集（JoyLo）

Challenge 1200+ 小时 teleop 数据由 JoyLo 采集。安装：

./setup.sh --joylo

joylo/README.md 说明：

  • 7-DoF R1-Pro 硬件组装（ASSEMBLY.md）
  • Nintendo JoyCon 蓝牙配置
  • 启动脚本：joylo/scripts/run_joylo.py、launch_og.py

核心模块：

路径 作用
gello/agents/joycon_agent.py JoyCon → 机器人 action
gello/robots/og_robot.py OmniGibson 机器人桥接
gello/utils/og_teleop_utils.py 任务加载、房间增广（eval 亦引用）

8. Motion Primitives（CuRobo）

./setup.sh --primitives

提供基于 CuRobo 的抓取/放置等 motion primitive（action_primitives/curobo.py）。若安装失败，可先跳过 --primitives，不影响基础仿真。

9. 宏与 Headless

from omnigibson.macros import gm

gm.HEADLESS = True                    # 无 GUI（在 import og 后、创建 env 前）
gm.ENABLE_OBJECT_STATES = True        # BehaviorTask 必需
gm.ENABLE_TRANSITION_RULES = True     # 烹饪/切片等规则
export OMNIGIBSON_GPU_ID=0            # 多卡时指定 GPU

10. 常见问题

现象 处理
首次 import 极慢 Omniverse 一次性编译/缓存
GPU 未识别 / 多卡 OMNIGIBSON_GPU_ID=0
--omnigibson 报错缺 bddl 必须同时 --bddl
--eval 报错 需 --joylo
数据集解密失败 确认 --dataset 完整下载且许可已接受
VRAM OOM load_object_categories 过滤；partial scene load
CuRobo / primitives 报错 跳过 --primitives 或更新驱动
HydraEngine rtx failed 设置 OMNIGIBSON_GPU_ID 为支持的 GPU

更多见 installation.md Troubleshooting。
