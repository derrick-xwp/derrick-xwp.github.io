TDW 基本使用流程

基于 Install · Controller
本地源码：https://github.com/threedworld-mit/tdw/blob/master/Python/ · 示例：example_controllers/

1. 系统要求

平台 要求
Linux Ubuntu 18/20/22；Python 3.8+；NVIDIA GPU + 驱动
macOS Sierra+；Flex 不支持
Windows Win10/11；Flex 流体完整支持

setup.py 声明 Python 3.6–3.11；依赖含 pyzmq（Controller 通信）、boto3（Build 下载）。

2. 安装

2.1 pip

pip3 install tdw

验证（自动下载 Build 并弹窗）：

from tdw.controller import Controller

c = Controller()
print("Hello world!")
c.communicate({"$type": "terminate"})

2.2 版本对齐

Controller(check_version=True) 会对比 tdw.version.__version__ 与 Build 的 send_version 输出。不匹配常见 crash/hang。

2.3 源码 editable 安装

git clone https://github.com/threedworld-mit/tdw.git
cd tdw/Python
pip3 install -e .

本地对照：https://github.com/threedworld-mit/tdw/blob/master/Python/。

3. 最小仿真循环

TDWUtils.create_empty_room 生成 create_exterior_walls 命令：

    def create_empty_room(width: int, length: int) -> dict:
        return {"$type": "create_exterior_walls", "walls": TDWUtils.get_box(width, length)}
from tdw.controller import Controller
from tdw.tdw_utils import TDWUtils

c = Controller()
c.communicate([TDWUtils.create_empty_room(12, 12)])
c.communicate({"$type": "terminate"})

官方推荐 继承 Controller 封装实验逻辑（见 example_controllers/ 各子目录）。

4. 图像采集（Add-on）

Add-on 在 communicate() 时 才发送命令；c.add_ons 顺序决定初始化与每帧注入顺序（见 controller.py L110–126）。

from tdw.controller import Controller
from tdw.tdw_utils import TDWUtils
from tdw.add_ons.third_person_camera import ThirdPersonCamera
from tdw.add_ons.image_capture import ImageCapture
from tdw.backend.paths import EXAMPLE_CONTROLLER_OUTPUT_PATH

camera = ThirdPersonCamera(
    position={"x": 2, "y": 1.6, "z": -0.6},
    avatar_id="a",
    look_at={"x": 0, "y": 0, "z": 0},
)
capture = ImageCapture(avatar_ids=["a"], path=EXAMPLE_CONTROLLER_OUTPUT_PATH.joinpath("image_capture"))

c = Controller()
c.add_ons.extend([camera, capture])
object_id = c.get_unique_id()
commands = [TDWUtils.create_empty_room(12, 12)]
commands.extend(c.get_add_physics_object(
    model_name="iron_box", position={"x": 0, "y": 0, "z": 0}, object_id=object_id,
))
c.communicate(commands)
c.communicate({"$type": "terminate"})

5. 程序化场景

5.1 Floorplan

Floorplan.init_scene 有效组合（源码 docstring）：

scene layout
1a / 1b / 1c … 5a / 5b / 5c 0, 1, 2 
from tdw.add_ons.floorplan import Floorplan

floorplan = Floorplan()
floorplan.init_scene(scene="1a", layout=0)
c.add_ons.append(floorplan)
c.communicate([])

5.2 ProcGenKitchen

from tdw.add_ons.proc_gen_kitchen import ProcGenKitchen

proc_gen_kitchen = ProcGenKitchen()
proc_gen_kitchen.create(rng=0)  # 固定种子可复现
c.add_ons.append(proc_gen_kitchen)
c.communicate([])

6. Replicant 最小交互

Replicant 动作是 异步状态机：调用 move_by 只设置 self.action，须每帧 communicate([]) 推进。

ActionStatus：

class ActionStatus(Enum):
    ongoing = 0
    failure = 1
    success = 2
    failed_to_move = 3
    collision = 8
    detected_obstacle = 9
    # ... cannot_grasp, still_dropping 等
from tdw.add_ons.replicant import Replicant
from tdw.replicant.action_status import ActionStatus

c = Controller()
replicant = Replicant(position={"x": 0, "y": 0, "z": 2})
c.add_ons.append(replicant)
c.communicate(TDWUtils.create_empty_room(12, 12))

replicant.move_by(2)
while replicant.action.status == ActionStatus.ongoing:
    c.communicate([])
c.communicate([])
print(replicant.action.status)

MoveBy 结束条件：到达距离、collision_detection 撞墙/障碍、连续同向失败等（见 action 类 docstring）。

多 Replicant：单 loop 内 communicate([]) 推进所有 agent，勿 per-agent blocking loop。

7. Clatter 音频最小示例

清单：AudioInitializer + Clatter + 物理物体；物体与 Clatter 同一 communicate() 加入最佳。

from tdw.add_ons.audio_initializer import AudioInitializer
from tdw.add_ons.clatter import Clatter

clatter = Clatter()  # 默认 simulation_amp=0.5, min_collision_speed=1e-5
c.add_ons.extend([camera, AudioInitializer(avatar_id="a"), clatter])

新项目用 Clatter，勿用已废弃 PyImpact。

8. 远程 Linux 服务器

服务器运行 binary_manager.py：

export TDW_BUILD_PATH=/path/to/build
python3 binary_manager.py --listening_port 5556 --gpus 0

本地 Controller 示例 minimal_remote.py：

class MinimalRemote(Controller):
    def __init__(self):
        build_info = RemoteBuildLauncher.launch_build(
            args.listening_port, args.build_address, args.controller_address)
        super().__init__(port=build_info["build_port"])

launch_build=False 时须自行保证 Build 已在对应端口监听。

10. 性能调优

问题 处理
慢 GPU 被 Build 使用；见 performance_optimizations
画质 {"$type": "set_render_quality", "render_quality": 5}
大数据集 少请求 send_*；FastTransforms + gzip

11. FAQ

现象 处理
无限 hang 端口占用；kill Build/Controller；换 port=
ZMQError: Address in use 同上
Build crash tdw 与 Build 版本；读 Unity Player.log
ftre 重发失败 Controller 与 Build socket 不同步；重启两者
无 GPU 可运行但慢；Clatter/Flex 受限
macOS damaged 移出 Downloads，运行 setup.sh

Bug 报告：GitHub Issues + 最小复现 + Player.log。

12. 推荐学习路径

  1. Core Concepts：Controller → Commands → Add-ons → Output Data
  2. Scene：Floorplan / ProcGenKitchen（floorplan.py）
  3. Agents：Replicant actions 或 Robot add-on
  4. Audio：Clatter（clatter.py）
  5. Physics：PhysX → Flex/Obi → tdw_physics

示例索引：Python/example_controllers/（embodied_avatars/、scene_setup_high_level/、robots/ 等）。
