## 1. Command 与 Output Data 模型

### 1.1 发送命令

```python
from tdw.controller import Controller

c = Controller()
c.communicate({"$type": "set_screen_size", "width": 1024, "height": 1024})
c.communicate([
    {"$type": "set_screen_size", "width": 1024, "height": 1024},
    {"$type": "simulate_physics", "value": False},
])
```

[`communicate`](https://github.com/threedworld-mit/tdw/blob/master/Python/tdw/controller.py) 将单条 dict 转为 list，合并 add-on 命令后 `json.dumps` → ZMQ multipart 发送。

常见错误：坐标须 `{"x":0,"y":0,"z":0}`，不可用 `[0,0,0]`。

### 1.2 接收 Output Data

```python
resp = c.communicate(commands)
frame = c.get_frame(resp[-1])
```

| 命令 | Output ID | 类 |
|------|-----------|-----|
| `send_images` | `imag` | [`Images`](https://github.com/threedworld-mit/tdw/blob/master/Python/tdw/output_data/images.py) |
| `send_transforms` | `tran` | `Transforms` |
| `send_rigidbodies` | `rigi` | `Rigidbodies` |

`frequency`：`"once"` | `"always"` | `"never"`。

Build 偶发 `ftre`（FailedToReceive）时 Controller **自动重发**同一命令包（最多 1000 次，见 `controller.py` L138–156）。

### 1.3 Add-on 机制

[`AddOn`](https://github.com/threedworld-mit/tdw/blob/master/Python/tdw/add_ons/add_on.py) 抽象：

```5:15:embodied-platforms/code/tdw-master/Python/tdw/add_ons/add_on.py
class AddOn(ABC):
    """
    Add-ons work by reading the response from the build and building a list of commands
    to be sent on the next `Controller.communicate(commands)` call.
    """
    def __init__(self):
        self.commands: List[dict] = list()
        self.initialized: bool = False
```

生命周期：`get_initialization_commands()` → 每帧 `on_send(resp)` 填充 `self.commands` → 下一帧 `communicate` 注入。

[`ObjectManager`](https://github.com/threedworld-mit/tdw/blob/master/Python/tdw/add_ons/object_manager.py) 自动订阅 transforms/rigidbodies，以 `dict[id → data]` 组织。

## 2. 图像 Pass

| Pass | 内容 |
|------|------|
| `_img` | RGB |
| `_id` / `_category` | 实例 / 语义分割 |
| `_depth` / `_depth_simple` | 深度 |
| `_flow` | 光流 |
| `_normals` / `_albedo` / `_mask` | 法线 / 反照率 / 遮罩 |

多 pass 采集（Command 方式）：

```python
commands.extend([
    {"$type": "set_pass_masks", "pass_masks": ["_img", "_id"], "avatar_id": "a"},
    {"$type": "send_images", "frequency": "always", "ids": ["a"]},
])
resp = c.communicate(commands)
for i in range(len(resp) - 1):
    if OutputData.get_data_type_id(resp[i]) == "imag":
        images = Images(resp[i])
        TDWUtils.save_images(images=images, filename="0", output_directory="./out")
```

**ImageCapture add-on** 等价封装；tdw_image_dataset 还用 **Occlusion** output 拒采差构图。

## 3. 音频：Clatter

### 3.1 初始化

1. 场景中有 **physics 物体**  
2. `AudioInitializer(avatar_id=...)`  
3. [`Clatter()`](https://github.com/threedworld-mit/tdw/blob/master/Python/tdw/add_ons/clatter.py)  
4. （可选）`resonance_audio=True` 空间化  

Clatter 构造参数（源码 L21–31 节选）：

| 参数 | 默认 | 含义 |
|------|------|------|
| `simulation_amp` | 0.5 | 全局音量缩放 |
| `min_collision_speed` | 1e-5 | 低于此速度忽略碰撞 |
| `scrape_angle` | 80° | 判定 scrape vs impact |
| `resonance_audio` | False | Resonance Audio 空间化 |
| `max_num_events` | 200 | 单帧最大 impact/scrape 事件数 |

底层命令：`initialize_clatter`、`clatterize_object`（见 Clatter `get_initialization_commands` / `on_send`）。

### 3.2 录制

- **`PhysicsAudioRecorder`** add-on → `.wav`  
- 离线 CLI：[clatter CLI 文档](https://github.com/threedworld-mit/tdw/blob/master/Documentation/lessons/clatter/cli.md)

### 3.3 TDW-Sound（论文）

5 材质 × 多物体 × drop 2–75 cm；VGG-16 AudioSet 预训练 → 真实测试 **66%** acc。

## 4. Replicant 动作 API

入口：[`Replicant`](https://github.com/threedworld-mit/tdw/blob/master/Python/tdw/add_ons/replicant.py)（非 avatar）。

| 方法 | Action 类 |
|------|-----------|
| `turn_by` / `turn_to` | `TurnBy` / `TurnTo` |
| `move_by` / `move_to` | [`MoveBy`](https://github.com/threedworld-mit/tdw/blob/master/Python/tdw/replicant/actions/move_by.py) / `MoveTo` |
| `reach_for` | `ReachFor` / `ReachForWithPlan` |
| `grasp` / `drop` | `Grasp` / `Drop` |
| `look_at` / `rotate_head` | `LookAt` / `RotateHead` |

### 4.1 Action 生命周期

```python
from tdw.replicant.action_status import ActionStatus

replicant.move_by(2)
while replicant.action.status == ActionStatus.ongoing:
    c.communicate([])
c.communicate([])
```

[`MoveBy`](https://github.com/threedworld-mit/tdw/blob/master/Python/tdw/replicant/actions/move_by.py) 成功/失败条件（docstring L22–31）：

- 走满 `distance` → **success**  
- 撞墙/物体且 `collision_detection.objects/walls` → **collision** / **failure**  
- `avoid_obstacles` 检测到障碍 → **detected_obstacle**  
- 连续同向 `move_by` 且上次失败 → 立即失败  

完整 `ActionStatus` 枚举见 [`action_status.py`](https://github.com/threedworld-mit/tdw/blob/master/Python/tdw/replicant/action_status.py)（含 `cannot_grasp`、`still_dropping` 等）。

### 4.2 初始化命令（源码）

Replicant spawn 时注入（[`replicant.py` L33–44](https://github.com/threedworld-mit/tdw/blob/master/Python/tdw/add_ons/replicant.py)）：

```python
{"$type": "add_replicant_rigidbody", "id": replicant_id}
{"$type": "set_rigidbody_constraints", ... "freeze_position_axes": {"x": 0, "y": 1, "z": 0}}
{"$type": "attach_empty_object", "empty_object_id": Arm.left/right, ...}
```

## 6. tdw_physics / Physion

抽象类（外部仓库 [tdw_physics](https://github.com/alters-mit/tdw_physics)）：

| 类 | 每帧 Output |
|----|-------------|
| `RigidbodiesDataset` | Transforms, Images, CameraMatrices, Rigidbodies, Collision |
| `FlexDataset` | + FlexParticles |

须覆写：`get_scene_initialization_commands`、`get_trial_initialization_commands`、`get_per_frame_commands`。

添加物体用 **`get_add_physics_object()`**（勿裸 `add_object`，否则 HDF5 元数据不一致）。

Physion 场景族：Object Permanence、Shadows、Collisions、Draping & Folding、Fluid-Solid 等（论文 Fig. 3）。

## 7. TDW-Image

仓库：[alters-mit/tdw_image_dataset](https://github.com/alters-mit/tdw_image_dataset)

| 项 | 值 |
|----|-----|
| 默认规模 | 1,300,000 train + 50,000 val |
| 分辨率 | 256×256 |
| 每图物体 | **1**（单物体标注假设） |
| 流程 | Positional loop（Occlusion 拒采）→ Image loop（全画质写盘） |

限制：不含 falling 物理（物体须在 positional loop 静止）。
