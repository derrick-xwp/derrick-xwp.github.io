## 1. 系统要求

| 平台 | 要求 |
|------|------|
| **Linux** | x86-64；NVIDIA GPU 推荐；无显示器需 X server 或 Docker |
| **macOS / Windows** | Windowed 模式运行 Build |
| **Python** | **3.x**（[`README.md`](https://github.com/xavierpuigf/virtualhome/blob/master/README.md) 明确基于 Python 3） |

[`requirements.txt`](https://github.com/xavierpuigf/virtualhome/blob/master/requirements.txt)：`numpy==1.17.3`、`opencv-python`、`requests`、`networkx==2.3`、`plotly` 等。

[`setup.py`](https://github.com/xavierpuigf/virtualhome/blob/master/setup.py) 注册 pip 包名 **`virtualhome`**（`version='0.0.1'`）。

## 2. 安装

### 2.1 pip 或源码

```bash
pip install virtualhome
# 或
git clone https://github.com/xavierpuigf/virtualhome.git
cd virtualhome
pip install -r requirements.txt
```

本地对照：`embodied-platforms/code/virtualhome-master/`。

### 2.2 下载 Unity Simulator

解压 Build 至 `simulation/unity_simulator/`。

**v2.3.0**（推荐复现 v2.3 特性）：

| 平台 | 链接 |
|------|------|
| Linux | [linux_exec.zip](http://virtual-home.org/release/simulator/v2.0/v2.3.0/linux_exec.zip) |
| macOS | [macos_exec.zip](http://virtual-home.org/release/simulator/v2.0/v2.3.0/macos_exec.zip) |

README 默认 `last_release` 链接可能较旧；**v2.3 请用上表**。

### 2.3 启动 Build

**有显示器**：

```bash
./simulation/unity_simulator/linux_exec/linux_exec.x86_64 \
  -screen-fullscreen 0 -screen-quality 4
```

**Headless Linux**（[`helper_scripts/startx.py`](https://github.com/xavierpuigf/virtualhome/blob/master/helper_scripts/startx.py)）：

```bash
sudo python helper_scripts/startx.py 0
DISPLAY=:0 ./linux_exec.x86_64 -batchmode
```

### 2.4 由 Python 自动拉起 executable

[`UnityCommunication.__init__`](https://github.com/xavierpuigf/virtualhome/blob/master/simulation/unity_simulator/comm_unity.py) 在传入 `file_name` 时创建 `UnityLauncher`：

```python
from simulation.unity_simulator.comm_unity import UnityCommunication

comm = UnityCommunication(
    file_name="/path/to/linux_exec.x86_64",
    port="8080",
    x_display="0",
)
```

内部通过 HTTP `post_command({'action': 'idle'})` 轮询连接（最多 5 次重试）。

## 3. 最小 API 流程

```python
from simulation.unity_simulator.comm_unity import UnityCommunication

comm = UnityCommunication(port="8080")
comm.reset(0)  # scene_index；v2.3 为 0–49

success, graph = comm.environment_graph()
print(len(graph["nodes"]), "nodes")

script = ["<char0> [walk] <kitchen> (1)"]
success, message = comm.render_script(
    script,
    recording=False,
    skip_animation=True,
    image_synthesis=[],
)
print(success, message)
comm.close()
```

> `pip install virtualhome` 后 import 路径可能为 `virtualhome.simulation...`；源码 clone 常用 `simulation.unity_simulator.comm_unity`。

`reset` 实现（HTTP `action: reset` + `intParams: [scene_index]`）：

```265:275:embodied-platforms/code/virtualhome-master/simulation/unity_simulator/comm_unity.py
    def reset(self, scene_index=None):
        response = self.post_command({'id': str(time.time()), 'action': 'reset',
                                      'intParams': [] if scene_index is None else [scene_index]})
        return response['success']
```

## 4. 生成活动视频

```python
comm.reset(4)
comm.add_character("Chars/Female1", initial_room="kitchen")

script = [
    "<char0> [walk] <microwave> (microwave_id)",
    "<char0> [open] <microwave> (microwave_id)",
    "<char0> [switchon] <microwave> (microwave_id)",
]

success, message = comm.render_script(
    script=script,
    recording=True,
    file_name_prefix="cook",
    image_width=640,
    image_height=480,
    frame_rate=5,
    image_synthesis=["normal"],
    skip_animation=False,
    find_solution=False,
    processing_time_limit=60,
)
```

批量生成：[`demo/generate_video.py`](https://github.com/xavierpuigf/virtualhome/blob/master/demo/generate_video.py)（README：`cd demo && python generate_video.py`）。

### 4.1 `render_script` 常用参数

| 参数 | 说明 |
|------|------|
| `recording` | 写视频到 `output_folder` |
| `skip_animation` | **`True`** 跳过动画（RL 必开） |
| `find_solution` | **`True`** 时用抽象 `(1)(2)`，Unity 自动匹配实例 |
| `image_synthesis` | `[]` 最快；或 `normal`/`depth`/`seg_inst`/`flow` |
| `save_scene_states` | 逐步保存图 |
| `processing_time_limit` | 单步超时（秒） |

### 4.2 多 agent 并行

```python
script = [
    "<char0> [walk] <salmon> (1) | <char1> [walk] <glass> (2)",
    "<char0> [grab] <salmon> (1) | <char1> [grab] <glass> (2)",
]
comm.add_character("Chars/Female1", initial_room="kitchen")
comm.add_character("Chars/Male1", initial_room="livingroom")
comm.render_script(script, skip_animation=False, recording=True)
```

`convert_action` 用 `|` 拼接多 agent script（[`utils.py` L6–27](https://github.com/xavierpuigf/virtualhome/blob/master/simulation/environment/utils.py)）。

## 8. Gym 风格 RL 环境

```python
from simulation.environment.unity_environment import UnityEnvironment

env = UnityEnvironment(
    num_agents=2,
    max_episode_length=200,
    observation_types=["partial", "partial"],
    base_port=8080,
    port_id=0,
    seed=123,
    recording_options={"recording": False},
)

obs = env.reset(environment_id=0, init_rooms=["kitchen", "bedroom"])
action_dict = {0: "walkforward", 1: "turnleft"}
obs, reward, done, info = env.step(action_dict)
# info['graph'] 为当前环境图
```

## 12. 常见问题（FAQ）

| 现象 | 处理 |
|------|------|
| 连接失败 | Build 已启动；改 `port`；`UnityCommunication.check_connection()` |
| Headless 失败 | X server + `DISPLAY` + `-batchmode` 或 Docker |
| `expand_scene` 失败 | 图 id 冲突；对照 `environment_graph()` |
| 脚本 message 报错 | 前置条件不满足；先用 Graph `ScriptExecutor` 预检 |
| RL 太慢 | `skip_animation=True`，`image_synthesis=[]` |
| 同类物体混淆 | `find_solution=True`，脚本用 `(1)(2)` |
| 数据集场景不匹配 | CVPR2019 包 + **v1.0**；v2.3 用 scene 0–49 |
