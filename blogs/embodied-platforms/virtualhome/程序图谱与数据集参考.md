## 1. 程序（Program）语法

### 1.1 Unity API 格式

[`simulation/README.md`](https://github.com/xavierpuigf/virtualhome/blob/master/simulation/README.md) 定义：

```
<char{id}> [action_name] <object_name> (object_id) [<object2> (id2)]
```

多 agent 同行用 `|`：

```python
program = [
    '<char0> [Walk] <chair> (1) | <char1> [Walk] <fridge> (1)',
    '<char0> [Sit] <chair> (1) | <char1> [Open] <fridge> (1)',
]
```

| 成分 | 说明 |
|------|------|
| `<char0>` | 与 `add_character` 顺序对应 |
| `[action]` | Walk / Grab / PutIn 等（Graph 侧见 `Action` 枚举） |
| `(id)` | **逻辑实例 ID**；同程序内相同 `(1)` 须指同一物体 |

### 1.2 数据集 `.txt` 格式

[`execute_script_utils.parse_exec_script_file`](https://github.com/xavierpuigf/virtualhome/blob/master/dataset_utils/execute_script_utils.py)：

- 行 0–1：标题 / 描述  
- 行 4+：动作行；executable 中 id 为 `1.23` 复合形式（场景 node id）

原始收集格式示例 [`example_script_1.txt`](https://github.com/xavierpuigf/virtualhome/blob/master/demo/example_scripts/example_script_1.txt)：

```
[Find] <plate> (1)
[Grab] <plate> (1)
...
```

### 1.3 `find_solution` 模式

| 模式 | 行为 |
|------|------|
| `find_solution=False` | `(id)` 须与环境图 node `id` 一致 |
| `find_solution=True` | 抽象 `(1)(2)`；Unity **自动选择**满足前置的实例 |

## 2. 环境图（Environment Graph）

### 2.1 Schema

```json
{
  "nodes": [
    {
      "id": 1,
      "class_name": "character",
      "category": "Person",
      "states": [],
      "properties": [],
      "bounding_box": {"center": [0,0,0], "size": [1,1,1]}
    }
  ],
  "edges": [
    {"from_id": 1, "to_id": 2, "relation_type": "INSIDE"}
  ]
}
```

### 2.2 物体状态与属性

| State | 含义 |
|-------|------|
| `OPEN` / `CLOSED` | 容器 |
| `ON` / `OFF` | 电器/灯 |

Graph 扩展：`plugged_in/out`、`clean/dirty`、`sitting/lying` 等（[`simulation/README.md` Preconditions](https://github.com/xavierpuigf/virtualhome/blob/master/simulation/README.md)）。

| Property（节选） | 影响动作 |
|------------------|----------|
| `GRABBABLE` | Grab |
| `CAN_OPEN` | Open/Close |
| `HAS_SWITCH` | SwitchOn/Off |
| `SURFACE` / `CONTAINERS` | PutBack / PutIn |
| `POURABLE` / `EATABLE` | Pour / Eat |

数据源：[`resources/properties_data.json`](https://github.com/xavierpuigf/virtualhome/blob/master/resources/properties_data.json)（Graph）、[`properties_data_unity.json`](https://github.com/xavierpuigf/virtualhome/blob/master/resources/properties_data_unity.json)（Unity）。

### 2.3 关系（relation_type）

| Relation | 含义 |
|----------|------|
| `ON` / `INSIDE` | 空间 |
| `CLOSE` / `FACING` | 可及 / 视野 |
| `HOLDS_RH` / `HOLDS_LH` | 持物 |
| `SITTING` | 坐 |
| `BETWEEN` | 门-房间 |

### 2.4 图 API

```python
comm.reset(scene_id)
success, graph = comm.environment_graph()
success, msg = comm.expand_scene(modified_graph)
```

**partial 观测**（RL）：`utils.get_visible_nodes(graph, agent_id=1)` — agent 图 id 通常为 `char_index + 1`。

`WalkExecutor.execute`（L73+）检查 sitting 状态、reachable、更新 `CLOSE`/`FACING` 边。

`ScriptExecutor.find_solutions(script)` 搜索满足前置的可执行图状态（见 [`demo/example.py`](https://github.com/xavierpuigf/virtualhome/blob/master/demo/example.py)）。

### 3.3 Unity 已支持动作（子集）

| 动作 | 简要前置 |
|------|----------|
| Walk / Run / WalkTowards / WalkForward | 非 sitting；reachable |
| Grab | close；手空闲 |
| Open / Close | close；空手 |
| PutBack / PutIn | 手持 obj1；容器状态合法 |
| SwitchOn / SwitchOff | close；`HAS_SWITCH` |
| Sit / StandUp | 容量限制 |

完整 Unity Executor 表见 [`simulation/README.md` § Actions](https://github.com/xavierpuigf/virtualhome/blob/master/simulation/README.md)（FindExecutor、GrabExecutor…）。

### 3.4 仅 Evolving Graph（或 Unity 未完整）

Wash / Rinse / Pour / Cut / Eat / Lie / PlugIn / Move / Watch / Wipe 等 — 见 `Action` 枚举与 README Executors 节。

## 4. RL `UnityEnvironment` 动作层

[`simulation/environment/utils.py`](https://github.com/xavierpuigf/virtualhome/blob/master/simulation/environment/utils.py)：

**`convert_action`** — 多 agent dict → script 字符串：

```6:27:embodied-platforms/code/virtualhome-master/simulation/environment/utils.py
def convert_action(action_dict):
    agent_do = [item for item, action in action_dict.items() if action is not None]
    script_list = ['']
    for agent_id in agent_do:
        script = action_dict[agent_id]
        current_script = ['<char{}> {}'.format(agent_id, script)]
        script_list = [x + '|' + y if len(x) > 0 else y for x, y in zip(script_list, current_script)]
    return script_list
```

**`can_perform_action`** — 基于图边检查 grab/open/close/put 是否合法（L47+）：`CLOSE` 边、`HOLDS_RH/LH`、容器 `OPEN`/`CLOSED` 状态等。

| RL 字符串 | 参数个数（`args_per_action`） |
|-----------|--------------------------------|
| `walkforward` / `turnleft` / `turnright` | 0 |
| `walktowards` / `grab` / `open` / `close` / `put` | 1 |
| `no_action` | 0 |

`get_action_space()`：partial 模式下返回当前可见 node id 作为交互候选。

### 6.1 对齐与 Unity 复现

[`execute_script_utils.py`](https://github.com/xavierpuigf/virtualhome/blob/master/dataset_utils/execute_script_utils.py) 流程：

1. `obtain_scene_id_from_path` → `TrimmedTestScene7` → `scene_id = 7` → **`comm.reset(6)`**  
2. `expand_scene(init_graph)` 来自 `init_and_final_graph`  
3. `render_script(executable 行)`  

```64:71:embodied-platforms/code/virtualhome-master/dataset_utils/execute_script_utils.py
def render_script_from_path(comm, path_executable_file, path_graph, output, character):
    scene_id = obtain_scene_id_from_path(path_graph)
    title, description, script = parse_exec_script_file(path_executable_file)
    with open(path_graph, 'r') as f:
        init_graph = json.load(f)['init_graph']
    result = render_script(comm, script, init_graph, scene_id-1, output, character)
```

## 8. Watch-And-Help Benchmark

论文：[arXiv:2010.09890](https://arxiv.org/abs/2010.09890)

| 角色 | 职责 |
|------|------|
| **Alice** | 主活动 + 演示 |
| **Bob** | Watch 推断 goal → Help 协作 |

| Split | 规模 |
|-------|------|
| Train | 1011 tasks |
| test-1 / test-2 | 各 100 tasks（test-2 多活动组合更难） |

| 指标 | 含义 |
|------|------|
| Success | 250 step 内满足全部 goal predicates |
| Speedup | \(L_{\text{Alice}} / L_{\text{Help}} - 1\) |
| Reward R | \(\sum_t \mathbf{1}(s^t=s_g) - 0.004\) |

## 10. Evolving Graph 独立使用

```python
from simulation.evolving_graph import utils
from simulation.evolving_graph.scripts import read_script
from simulation.evolving_graph.execution import ScriptExecutor

graph = utils.load_graph("scene.json")
executor = ScriptExecutor(graph, utils.load_name_equivalence())
script = read_script("program.txt")
state = next(executor.find_solutions(script), None)
```

**用途**：批量验证可执行性、生成 `state_list`、符号规划。  
**限制**：动作集与 Unity **不完全一致**；发布前应在目标 Build 上 `render_script` 抽检。

Preparation 链（缺物体/随机增广/改开关状态）：[`preparation.py`](https://github.com/xavierpuigf/virtualhome/blob/master/simulation/evolving_graph/preparation.py) — `AddMissingScriptObjects`、`ChangeObjectStates` 等。

## 11. 与 AI2-THOR / CHALET 对比

| 维度 | VirtualHome | AI2-THOR | CHALET |
|------|-------------|----------|--------|
| 程序 | 线性 script + 图 | controller.step | 自然语言+离散动作 |
| 状态 | **graph JSON** | event + metadata | CIFF |
| 多 agent | `\|` 语法 | multi-agent step | 多角色 |
