AI2-THOR 动作与对象参考

权威来源：Agent Actions · Environment State / Object Metadata · ManipulaTHOR API
源码对照：controller.py · constants.py
延伸阅读：介绍.md · 基本使用流程.md

本文档汇总 iTHOR default agent 与 ManipulaTHOR arm agent 常用动作及 object metadata 字段，并补充 源码中的容器相容表与可移动物体列表，便于离线查阅。

1. 调用约定

event = controller.step(action="ActionName", param1=value1, ...)
# 或
event = controller.step("MoveAhead")

实现见 controller.py L1011–1054：step 将 action dict 经 self.server.send(action) 发往 Unity。

  • 成功：event.metadata["lastActionSuccess"] == True
  • 查询类动作：结果在 event.metadata["actionReturn"]
  • 失败：阅读 event.metadata["errorMessage"]

查询动作（GetReachablePositions 等）不改变 环境状态，可复用上一帧图像，通常更快。

2. 容器相容性（RECEPTACLE_OBJECTS）

controller.py 在模块顶层定义 RECEPTACLE_OBJECTS（L48+），映射 容器 objectType → 可放入的物体 objectType 集合。PutObject 失败时，可对照此表检查类别是否兼容。

容器 可放入物体（节选）
Box Candle, CellPhone, Cloth, CreditCard, KeyChain, Newspaper, SoapBar, …
Cabinet Bowl, Mug, Plate, Laptop, Toaster, Pan, Pot, Bread, Knife, …
CoffeeMachine Mug, MugFilled
CounterTop Apple, Bread, CoffeeMachine, Egg, Fork, Knife, Mug, Plate, …
DiningTable 与 CounterTop 类似，含 Laptop, Vase, Statue 等
Drawer CellPhone, CreditCard, KeyChain, Knife, Mug, RemoteControl, …
Fridge Apple, Bowl, Egg, Lettuce, Potato, Tomato, WineBottle, …
Microwave Apple, Bowl, Mug, Potato, Tomato, Egg, …
Sink Bowl, Cup, Mug, Plate, Potato, Tomato, …
SinkBasin Apple, Bowl, Cup, Egg, Mug, Potato, …

完整集合见官方源码；该表与 Unity 侧 receptacle 逻辑一致，也用于 Python 侧 最近枢轴点 计算（Controller.receptacle_nearest_pivot_points，L402）。

3. 导航与视角（default / locobot）

动作 主要参数 说明
MoveAhead moveMagnitude=0.25 沿朝向前进
MoveBack moveMagnitude 后退
MoveLeft / MoveRight moveMagnitude 侧移
RotateRight / RotateLeft degrees=90 水平旋转
LookUp / LookDown degrees=30 俯仰 camera horizon
Teleport x,y,z 或 position 瞬移到点
TeleportFull position, rotation, horizon, standing 完整姿态
Crouch / Stand — 蹲/站
Done — episode 结束信号（RL）

网格步长由 Controller 的 gridSize（默认 0.25m）约束；碰撞时动作失败。

4. 物体交互（default agent）

动作 主要参数 前置条件（object metadata）
PickupObject objectId, forceAction=False pickupable=True, 通常需 visible
PutObject objectId（容器） 手持物体；目标为 receptacle；类别需符合 §2
DropHandObject — 手中有物体
OpenObject objectId openable=True, isOpen=False
CloseObject objectId openable=True, isOpen=True
ToggleObjectOn / ToggleObjectOff objectId toggleable=True
SliceObject objectId sliceable=True
BreakObject objectId breakable=True
CookObject objectId cookable=True（常在 stove/microwave 上下文）
DirtyObject / CleanObject objectId dirtyable
FillObjectWithLiquid objectId, fillLiquid fillable / 液体源
EmptyLiquidFromObject objectId 容器有液体
UseUpObject objectId canBeUsedUp（如纸巾）

物理推动

动作 说明
PushObject 沿方向推 moveable 物体
PullObject 拉
DirectionalPush 指定方向推力
ThrowObject 投掷手中物体

5. 环境查询

动作 参数 actionReturn
GetReachablePositions — [{x,y,z}, ...] 可导航点
GetObjectInFrame x, y ∈ [0,1] 归一化坐标 objectId 或 None
GetCoordinateFromRaycast x, y 射线命中点
GetInteractablePoses objectId 可交互位姿列表
GetVisibleObjects — 可见 objectId 列表

典型模式：先用 GetObjectInFrame 或遍历 metadata["objects"] 获取 objectId，再调用交互动作。

query = controller.step(action="GetObjectInFrame", x=0.64, y=0.40, checkVisible=False)
oid = query.metadata["actionReturn"]
if oid:
    controller.step(action="OpenObject", objectId=oid)

6. 场景与渲染控制

动作 说明
CreateHouse ProcTHOR：载入 house JSON
RandomizeLighting 光照随机化（域随机化）
AddThirdPartyCamera 添加固定外部相机
UpdateThirdPartyCamera 更新外部相机
PausePhysicsAutoSim / AdvancePhysicsStep 手动步进物理
InitializeObject 重置/初始化物体状态

7. ManipulaTHOR 专用动作（agentMode="arm"）

7.1 底座与身体

动作 参数 说明
MoveAgent ahead, right, returnToStart, speed 可 对角线 移动（不同于 MoveAhead）
RotateAgent degrees, returnToStart, speed 旋转身体

7.2 机械臂

动作 说明
MoveArm 多自由度臂运动（position/rotation 等，见官方文档）
MoveArmBase 臂基座平移
PickupObject 臂端抓取
ReleaseObject 释放
SetHandSphereRadius 调整抓取碰撞球半径

7.3 相机

动作 说明
RotateHand / RotateHandRelative 腕部相机旋转
Teleport / TeleportFull 整体瞬移

臂 metadata 含 joint 角度、hand 位姿等，见 ManipulaTHOR Metadata 的 Arm/Joint Metadata 节。

8. Object Metadata 字段详解

每个 metadata["objects"][i] 为 dict，常用字段：

8.1 标识

字段 类型 说明
objectId str Type|x|y|z 唯一 ID
objectType str 语义类（Apple, Fridge, …）
name str Unity 场景内唯一名

8.2 位姿与可见性

字段 说明
position {x,y,z} 世界坐标（y 向上）
rotation {x:pitch, y:yaw, z:roll}
distance 物体中心到 agent 相机距离
visible 在 visibilityDistance 内且满足可见性规则

8.3 几何

字段 说明
axisAlignedBoundingBox 世界轴对齐包围盒（随旋转变）
objectOrientedBoundingBox 物体自身坐标系 OBB（pickupable）

8.4 物理

字段 说明
mass 千克（pickupable/moveable）
salientMaterials 材质标签列表

8.5 容器关系

字段 说明
parentReceptacles 父容器 objectId 列表
receptacle 是否为容器
receptacleObjectIds 内容物 id 列表

8.6 状态 flags（节选）

字段 含义
isOpen 门/抽屉/电器门开
isToggled 开关打开
isBroken 已打碎
isSliced 已切片
isCooked 已烹饪
isDirty 脏
isFilledWithLiquid 含液体
isPickedUp 被 agent 持有
isMoving 物理运动中

8.7 温度

字段 值
ObjectTemperature Hot / Cold / RoomTemp
canChangeTempToHot 可作为热源
canChangeTempToCold 可作为冷源

9. 可移动物体列表（ManiSkill 对照）

在 ManiSkill 的 HSSD 集成中，load_ai2thor_metadata() 读取 object_semantic_id_mapping.json，并定义 MOVEABLE_OBJECT_IDS（constants.py L34–140）。AI2THORBaseSceneBuilder._should_be_static() 用此列表决定物体建为 static 还是 dynamic actor（scene_builder.py L98–108）。

与 Unity metadata 中 moveable / pickupable 大体对应，节选如下：

类别 objectType 示例
食物 Apple, Tomato, Bread, Potato, Lettuce, Egg, Sandwich
餐具 Bowl, Mug, Plate, Cup, Fork, Knife, Spoon
电器小件 Toaster, CoffeeMachine, DeskLamp, VacuumCleaner
日用品 CellPhone, Laptop, Book, KeyChain, CreditCard, TissueBox
清洁 SoapBottle, DishSponge, ScrubBrush, SprayBottle
运动/装饰 BaseballBat, BasketBall, TennisRacket, TeddyBear, Vase
家具（可推） Chair, Stool, Footstool, Cart

完整列表见源码。另有一组 WORKING_OBJS（scene_builder.py L43–52：apple, potato, tomato, lettuce, soap, sponge, plate, book），在 ManiSkill 中 强制 建为 dynamic actor 以便操作实验。

注意：ManiSkill 路径 不实现 Unity 侧的 Open/Cook/Slice 等语义状态；仅提供刚体碰撞与抓取物理。

10. Agent Metadata（节选）

metadata["agent"] 常见字段：

字段 说明
position / rotation agent 身体位姿
cameraHorizon 相机俯仰
isStanding / isCrouching 姿态
heldObjects 持有物体信息

ManipulaTHOR 另有 arm、joint 子结构。

11. objectType 类别

AI2-THOR 定义数百种 objectType（厨房电器、食物、家具等），完整列表见官方 Object Types 文档：

https://ai2thor.allenai.org/ithor/documentation/objects

常见类别示例：

  • 可开容器：Drawer, Cabinet, Fridge, Microwave, Safe
  • 可切换：LightSwitch, DeskLamp, StoveKnob, Faucet
  • 可拾取：Apple, Bread, Mug, CellPhone, Key
  • 大型固定：CounterTop, DiningTable, Sofa, Bed

RoboTHOR 14 类导航目标 包括 AlarmClock, BaseballBat, BasketBall, Box, CellPhone, Chair, Cup, Laptop, Mug, SprayBottle, TennisRacket, ToiletPaper, ToyBear, Vase 等（见 RoboTHOR 论文 Fig.2）。其中多数亦在 MOVEABLE_OBJECT_IDS 中。

12. 性能提示

  1. 仅在需要时开启 renderDepthImage / renderInstanceSegmentation
  2. 用 查询动作 代替重复 step 获取可达点
  3. 集群使用 CloudRendering
  4. 批量实验考虑 多进程 Controller（见 legacy multi-threaded example）
  5. v2.7.0+ 对渲染管线有显著提速（见 官网 News）
  6. ManiSkill 大规模采集：提高 num_envs，使用 render_mode="rgb_array"（见 ../sapien/介绍.md）
