# AI2-THOR 基本使用流程

> 官方：[Installation & First Steps](https://ai2thor.allenai.org/ithor/documentation/)  
> 源码：[controller.py](https://github.com/allenai/ai2thor/blob/master/ai2thor/controller.py) · 本地 ManiSkill 集成：[scene_builder/ai2thor/](../code/ManiSkill-main/mani_skill/utils/scene_builder/ai2thor/)  
> 延伸阅读：[介绍.md](介绍.md) · [动作与对象参考.md](动作与对象参考.md)

## 概述

标准流程：**安装 ai2thor → 初始化 Controller（自动下载 Unity build）→ step 循环 → 读取 Event → stop/reset**。  
ManipulaTHOR / RoboTHOR / ProcTHOR 在同一包内通过 **不同 `agentMode`、scene、action** 切换。

另有一条 **跨平台路径**：在 ManiSkill 中下载 HSSD 压缩资产，用 SAPIEN GPU 并行加载 AI2-THOR 场景（无语义状态机，适合大规模探索与合成数据）。见 [§流程十二](#流程十二maniskill--hssd-场景探索)。

## 流程一：安装

### 方式 A：PyPI（推荐）

```bash
pip install ai2thor
# 或
conda install -c conda-forge ai2thor
```

### 方式 B：锁定 Git commit（复现）

```bash
# 示例 commit（以官方文档为准）
pip install --extra-index-url https://ai2thor-pypi.allenai.org \
  ai2thor==0+d74c4a9bf9ec558f27d4bd1779d5e33983b99db0
```

### 方式 C：ProcTHOR 生成器（独立包）

```bash
pip install procthor
```

### 方式 D：本地克隆官方仓库（可选）

```bash
cd embodied-platforms/repos
bash fetch_repos.sh   # 或单独克隆 ai2thor
# Unity 二次开发见 unity/README
```

### 首次运行

首次 `Controller()` 会下载 Unity 场景包到 **`~/.ai2thor`**（约 **500MB**），需联网。`Controller` 构造函数支持 `download_only=True` 仅预下载（[controller.py L389](https://github.com/allenai/ai2thor/blob/master/ai2thor/controller.py#L389)）。

## 流程二：最小验证

```python
from ai2thor.controller import Controller

controller = Controller(scene="FloorPlan10")
event = controller.step("MoveAhead")
print(event.metadata["lastActionSuccess"])
print(event.metadata["agent"]["position"])
controller.stop()
```

`step` 可传字符串 shorthand：`controller.step("MoveAhead")` 等价于 `controller.step(action="MoveAhead")`（[controller.py L1011–1018](https://github.com/allenai/ai2thor/blob/master/ai2thor/controller.py#L1011-L1018)）。

## 流程三：指定场景与渲染

```python
from ai2thor.controller import Controller

controller = Controller(
    scene="FloorPlan203",
    width=640,
    height=480,
    fieldOfView=90,
    gridSize=0.25,
    visibilityDistance=1.5,
    renderDepthImage=True,
    renderInstanceSegmentation=True,
)

event = controller.step(action="RotateRight")
rgb = event.frame              # H×W×3
depth = event.depth_frame      # 需 renderDepthImage
cv2img = event.cv2img          # OpenCV BGR

controller.stop()
```

运行时切换场景：

```python
controller.reset(scene="FloorPlan15", fieldOfView=80)
```

## 流程四：无头 / 集群（Cloud Rendering）

默认会打开 Unity 窗口。在 **无 X11 的集群** 上使用：

```python
from ai2thor.controller import Controller
from ai2thor.platform import CloudRendering

controller = Controller(platform=CloudRendering)
event = controller.step("MoveAhead")
```

- 2022 年 2 月起官方推荐方式（见 [Cloud Rendering 文档](https://ai2thor.allenai.org/ithor/documentation/cloud-rendering)）  
- 需要 NVIDIA GPU；`nvidia-smi` 不可用时会报错（[controller.py L1160](https://github.com/allenai/ai2thor/blob/master/ai2thor/controller.py#L1160)）  
- 替代方案：[ai2thor-docker](https://github.com/allenai/ai2thor-docker) 配置虚拟 X server

## 流程五：物体交互示例

```python
from ai2thor.controller import Controller

controller = Controller(scene="FloorPlan10")

# 1. 获取场景中所有物体类型
event = controller.step(action="Pass")
for obj in event.metadata["objects"]:
    if obj["objectType"] == "Microwave":
        microwave_id = obj["objectId"]
        break

# 2. 打开微波炉
event = controller.step(action="OpenObject", objectId=microwave_id)
assert event.metadata["lastActionSuccess"], event.metadata["errorMessage"]

# 3. 拾取苹果（需先找到 pickupable 且 visible）
apple = next(o for o in event.metadata["objects"]
             if o["objectType"] == "Apple" and o["pickupable"] and o["visible"])
event = controller.step(action="PickupObject", objectId=apple["objectId"])

# 4. 放入微波炉
event = controller.step(action="PutObject", objectId=microwave_id)
event = controller.step(action="CloseObject", objectId=microwave_id)

controller.stop()
```

失败时检查 `event.metadata["errorMessage"]`（如物体不可见、距离过远、容器已满）。`PutObject` 的容器相容性可参考 `controller.py` 中的 `RECEPTACLE_OBJECTS`（见 [动作与对象参考.md §2](动作与对象参考.md)）。

## 流程六：ManipulaTHOR 机械臂

**必须** `agentMode="arm"`：

```python
from ai2thor.controller import Controller

controller = Controller(
    agentMode="arm",
    scene="FloorPlan203",
    visibilityDistance=1.5,
    gridSize=0.25,
    width=300,
    height=300,
    fieldOfView=60,
    renderDepthImage=False,
    renderInstanceSegmentation=False,
    massThreshold=5.0,  # 可选：限制臂直接推动的物体质量
)

# 移动底座（可对角线）
controller.step(action="MoveAgent", ahead=0.25, right=0.0, returnToStart=True)

# 旋转
controller.step(action="RotateAgent", degrees=30)

# 移动机械臂（见 ManipulaTHOR 文档 MoveArm 参数）
# controller.step(action="MoveArm", ...)

# 抓取
# controller.step(action="PickupObject", objectId="...", forceAction=True)

controller.stop()
```

ManipulaTHOR 使用 **iTHOR 场景**，但动作为 **连续/低层** 臂控，与 default agent 的离散 MoveAhead 不同。  
完整臂动作见 [ManipulaTHOR API](https://ai2thor.allenai.org/manipulathor/documentation/) 与 [动作与对象参考.md](动作与对象参考.md)。

## 流程七：RoboTHOR（LoCoBot）

```python
controller = Controller(
    agentMode="locobot",
    scene="FloorPlan_Train1_1",  # RoboTHOR 场景命名见文档
    gridSize=0.25,
    fieldOfView=60,
)
```

- 训练在 60 个 train 场景；test-dev/test-standard 对应真实公寓  
- 真实部署通过 AI2 远程测试基础设施（见 [RoboTHOR 论文](https://arxiv.org/abs/2004.06799)）  
- 与 PyRobot LoCoBot API 对齐设计  
- 若未设 `agentMode='locobot'` 而加载 RoboTHOR 场景，`reset` 会抛出明确错误（[controller.py L713–717](https://github.com/allenai/ai2thor/blob/master/ai2thor/controller.py#L713-L717)）

场景列表：[RoboTHOR Demo 页](https://ai2thor.allenai.org/demo/)

## 流程十二：ManiSkill + HSSD 场景探索

当目标是 **GPU 并行加载 AI2-THOR 室内场景**（而非 Unity 语义状态机）时，可使用本地 ManiSkill 集成代码。

### 12.1 安装 ManiSkill 并下载资产

```bash
pip install mani-skill
# 列出可下载的场景数据集
python -m mani_skill.utils.download_asset --list "scene"
# 下载 AI2-THOR 场景包（体积大、较慢）
python -m mani_skill.utils.download_asset AI2THOR
```

下载 URL 与目标路径定义于 [data.py L128–132](../code/ManiSkill-main/mani_skill/utils/assets/data.py#L128-L132)：

```
https://huggingface.co/datasets/haosulab/AI2THOR/resolve/main/ai2thor.zip
→ scene_datasets/ai2thor/
```

原始 HSSD 配置与 GLB 资产来源：[hssd/ai2thor-hab](https://huggingface.co/datasets/hssd/ai2thor-hab)（[scene_builder.py L2](../code/ManiSkill-main/mani_skill/utils/scene_builder/ai2thor/scene_builder.py#L2) 文件头注释）。

### 12.2 运行预置环境

```bash
# ArchitecTHOR（文档中最常用示例，10 个场景）
python -m mani_skill.examples.demo_random_action \
  -e "ArchitecTHOR_SceneManipulation-v1" \
  --render-mode="rgb_array" --record-dir="videos"

# GUI 模式，seed=3 采样第 4 个场景配置
python -m mani_skill.examples.demo_random_action \
  -e "ArchitecTHOR_SceneManipulation-v1" --render-mode="human" -s 3

# 4 并行 env + Fetch 机器人
python -m mani_skill.examples.demo_random_action \
  -e "RoboCasaKitchen-v1" \
  -n 4 -s 0 1 2 3 --render-mode="human" -r "fetch"

# 无 agent，仅浏览场景
python -m mani_skill.examples.demo_random_action \
  -e "iTHOR_SceneManipulation-v1" -r "none" --render-mode="human"
```

环境 ID 由 [scenes/__init__.py L17–22](../code/ManiSkill-main/mani_skill/envs/scenes/__init__.py#L17-L22) 自动注册：`{SceneBuilderName}_SceneManipulation-v1`。

### 12.3 Python API 示例

```python
import gymnasium as gym
import mani_skill.envs  # 触发环境注册

env = gym.make(
    "ArchitecTHOR_SceneManipulation-v1",
    num_envs=4,
    robot_uids="fetch",
    render_mode="rgb_array",
)
obs, info = env.reset(seed=0)
# obs 含相机 RGB；场景由 AI2THORBaseSceneBuilder.build() 构建
env.close()
```

`SceneManipulationEnv` 支持 `scene_builder_cls` 参数切换四套子环境（[base_env.py L32–34](../code/ManiSkill-main/mani_skill/envs/scenes/base_env.py#L32-L34)），当前 **无预定义 reward**，仅适合探索与可视化。

### 12.4 与 Unity 路径的选择

| 需求 | 推荐路径 |
|------|----------|
| Open/Cook/Slice 等语义状态 | Unity `Controller` |
| RoboTHOR Sim2Real、LoCoBot | Unity `agentMode="locobot"` |
| 大规模并行 RGBD 采集、场景 benchmark | ManiSkill + HSSD |
| ALFRED / 语言交互任务 | Unity（或 ALFRED 专用 fork） |

## 常见问题

| 问题 | 处理 |
|------|------|
| `lastActionSuccess=False` | 读 `errorMessage`；检查 `visible`、距离、物体属性 |
| Linux 无 DISPLAY | `CloudRendering` 或 Docker |
| 下载 build 失败 | 检查网络；可 `download_only=True` 预下载 |
| 深度/分割太慢 | 仅在需要帧时开启 render flags |
| ManipulaTHOR 行为异常 | 确认 `agentMode="arm"` |
| RoboTHOR 场景报错 | 确认 `agentMode="locobot"` |
| 内存/leak | 每 episode 后 `controller.stop()` 或 `reset` |
| GPU 选择 | `Controller(gpu_device=0)` |
| ManiSkill 场景物体不能「打开冰箱」 | 预期行为：HSSD 路径无语义状态机，仅刚体物理 |
| ManiSkill 下载慢 | `AI2THOR` 包体积大；可先试 `ReplicaCAD` |
